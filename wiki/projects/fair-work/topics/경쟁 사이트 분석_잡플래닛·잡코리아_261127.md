# 🔍 경쟁 사이트 분석: 잡플래닛·잡코리아 기업 리뷰

상위: [[fair-work]] · 기획: [[원어민 교사 앱 기획_261126]] · 비교: [[경쟁 사이트 분석_ESL Whitelist Korea_261126]]

- 조사: agy(구글 검색, 2026-11-27). 로그인 안쪽 화면 문구는 검색으로 확인 못 한 것이 있음.
- 목적: Midnight Run Korea 리뷰에 가져올 것 고르기. 기존 결정(순위 없음·재직 여부 안 받음·근무 확인 사진 안 함·학원 계정 없음·리크루터 안 다룸)과 부딪히는 것은 뺀다.

## 1. 두 사이트 요약

| | 잡플래닛 | 잡코리아 |
|---|---|---|
| 별점 | 전체 + 5개(복지·급여 / 워라밸 / 사내 문화 / 승진 / 경영진) | 전체 + 6개(연봉 / 워라밸 / 복리후생 / 조직문화 / 커리어 성장 / 고용안정성) |
| 글 칸 | 한줄평 / 장점 / 단점 / 경영진에 바라는 점(각 50~1,000자) | 장점 / 단점 / 한줄평 + 키워드 |
| 객관식 | 추천 여부(추천율)·CEO 지지·1년 후 성장 전망 | 추천 여부·성장 전망 |
| 작성자 표시 | 직무·현직/전직·지역·고용형태·작성일 | 재직/퇴사·직무 |
| 열람 | **기여 후 열람**: 1건 쓰고 승인되면 1년 무료, 아니면 유료 멤버십 | 로그인만 하면 기본 리뷰 무료 |
| 기업 페이지 | 종합 점수 + 항목 레이더·막대, **연도별 추이**, AI 요약·키워드, 연봉·면접·복지 탭 | 6개 항목 그래프, 기업 비교(VS), 연봉·면접 탭 |
| 면접 후기 | 직무·시기·경로 / 난이도 5단계 / 경험 긍정·보통·부정 / 합격 여부 / 받은 질문·팁 | 비슷 + 면접 방식·분위기·결과 통보 기간 |
| 안전 | 익명, 고용보험 인증(미인증은 '미인증 리뷰' 표시), 기업 답변, 정보통신망법 44조의2 임시조치 최대 30일, 도움돼요·신고 | 익명, 이력서 경력 연계 인증, 임시조치, 도움돼요·신고 |

- 2025-12 잡코리아가 잡플래닛을 인수, 2026-01 자회사로 편입(agy 조사, 출처 기사 기준).

## 2. 우리와 비교

| 잡플래닛·잡코리아 | 지금 Midnight Run Korea | 판단 |
|---|---|---|
| 세부 별점 5~6개 | 전체 + 원장 2개 | **가져올 만함**: 급여·숙소·업무량 정도만 더하기 |
| 장점 / 단점 / 바라는 점 칸 | 글 칸 1개(500자) | **가져올 만함**: 읽는 사람이 바로 비교 |
| 추천 여부 | 없음 | **가져올 만함**: "친구에게 권하겠나" 한 문항, 비율 표시 |
| 면접 후기 | 없음 | **가져올 만함**: 계약 전 정보, 일 안 한 사람도 쓸 수 있어 글이 늘어남 |
| 연봉 정보 | 없음(체크 항목만) | **가져올 만함(조심)**: 월급·주당 시간·숙소 제공을 구간으로. 리뷰 적으면 사람이 드러나서 3건 넘을 때만 평균 |
| 연도별 추이 | 없음 | 리뷰가 쌓인 뒤. 근무 연도로 묶기만 |
| 도움돼요 | 없음(가짜 신고만) | **가져올 만함**: Lounge의 Me too와 같은 방식 |
| 기업 답변 | 있음(양식 → 운영자가 올림) | 이미 있음 |
| 임시조치 30일 | 삭제 요청 → 운영자 기준표 | 이미 비슷 |
| 기여 후 열람 | 승인제(리뷰 안 써도 읽음) | 사용자 결정 필요 — 새로 오는 교사는 쓸 게 없음 |
| 재직 인증·현직/전직 | 안 받음(결정) | 안 함 |
| 기업 비교·순위 | 안 함(결정) | 안 함 |
| AI 요약 | 주제 분류(낱말)만 | 안 함 — 무료 API 키는 학습에 쓰여 남의 글을 보내지 않음 |
