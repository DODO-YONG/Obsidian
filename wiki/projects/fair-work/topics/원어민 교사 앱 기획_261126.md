# 원어민 교사 앱 기획 (학원 평가·리뷰)

상위: [[fair-work]]

**이름: Midnight Run Korea**(사용자 결정 2026-11-26) · 코드명 **DY-010 LOOKOUT** · 소개 문구 "Avoid the midnight run — check before you sign." · 무료 주소 midnightrunkorea.vercel.app(도메인은 돈이 들어 나중에)

## 한 줄
한국의 원어민 교사(E-2)가 **학원 평가·리뷰를 남기고, 취업 전에 쉽게 확인**하는 영어 앱. 잡플래닛·블라인드의 안전장치를 따라 한다. 근거는 [[외국인 노동자 부당 대우 조사_261126]].

> **범위 줄임**(사용자 결정 2026-11-26): "계약서까지 가면 부담스럽다. 평가·리뷰를 남겨 사람들이 쉽게 확인하는 것"이 목표. → 계약서 점검·돈 계산·진정서·증거 금고(C)는 **하지 않는다**. 남는 것: 학원 검색 + 리뷰 쓰기·보기 + 최소한의 법적 안전장치 + 도움 연락처 링크. 아래 C 칸은 기록으로만 남김.

## 왜 원어민 교사부터
- 영어 하나로 된다(E-9는 10개+ 언어).
- 페이스북 그룹·레딧에 모여 있고, 블랙리스트 글이 이미 돌고 있다 = 수요가 있다.
- 기존 도구(Tokyo Jon·레딧)는 검색이 불편하고 검증이 없고, 잡플래닛·블라인드는 한국어·회사 이메일이라 못 쓴다.
- 언어교환 앱([[language-exchange]])의 첫 외국인 사용자와 같은 사람들 — 서로 소개할 수 있다.
- 나중에 같은 엔진으로 E-9 등 다른 외국인 노동자로 넓힌다(언어·비자 규칙만 바꿈).

- **한 줄 차별점**: "모든 등록 학원이 검색되고, 리뷰를 쉽게 남기고 쉽게 본다."
- **실제 쓰는 방식(사용자 확인 2026-11-26)**: 교사는 **학원 이름을 검색해서 다른 사람들의 평가를 읽는다** — 이것이 핵심 동작. 따라서 **리뷰를 처음 공개 때부터 같이** 연다(사용자 결정 2026-11-26). 리뷰가 아직 없는 학원은 **외부 리뷰 검색 링크(Tokyo Jon·레딧·ESL Whitelist)**를 크게 두어 빈손이 되지 않게 한다.
- **첫 번째로 데려올 사용자 = Tokyo Jon 사용자**: 지금도 교사들이 실제로 보고 있는 사이트임을 확인(2026-11-26). 화면은 옛날식이고 곧 닫힐 예정 → 그 사용자들이 쓰던 방식(학원 이름으로 찾기, 영어, 짧은 경험담)을 1단계 화면의 기준으로 삼는다.
- **협력 가능성**: 경쟁하면서도 외부 검색 링크로 두 곳을 연결해 둔다(교사에게 이득, 우리 위험은 낮음). Tokyo Jon이 닫히면 그 사용자들이 옮겨 갈 곳이 되도록 1단계를 그 전에 연다.

## 기능

### A. 학원 확인 (구직 전)
- **영어로 찾기**(사용자 결정 2026-11-26, 둘 다): 나이스엔 한글 이름뿐인데 교사는 영어 이름(Chungdahm·Poly·JLS)·동네 이름(Bundang·Ilsan)으로 찾는다. → ① 학원 이름·주소를 **자동 로마자 변환**(국어의 로마자 표기법), ② **큰 체인 50~100개는 영어 이름 표**를 직접 만들어 묶음(예: 청담 → Chungdahm April), ③ 리뷰 쓸 때 **'이 학원 영어 이름'을 교사가 추가**해서 점점 채움. 계약서의 한글 이름을 붙여 넣어도 찾아짐.
- **검색**: 학원 이름·지역·사업자등록번호. 같은 나이스 지정번호면 이름이 바뀌어도 하나로 본다. **폐원 뒤 같은 주소에 새로 연 학원은 연결하지 않는다**(사용자 결정 2026-11-26: 주인이 실제로 바뀐 경우 잘못된 정보가 됨).
- **공식 자료 칸**: 정부 공개 자료(체불 명단·국민연금 가입 사업장·학원 등록 상태)를 출처·날짜와 함께 그대로. 공개 기간이 끝나면 내린다. 아래 "공개 데이터".
- **화면 구성**(사용자 결정 2026-11-26, 그림으로 확인): 학원 페이지 위에는 **사실만** — 이름(영어·한글·다른 이름)·동네·주소·개설일, 공개 자료(교육청·국민연금·체불, 출처·기준일), 확인할 질문, 외부 검색 링크. **원장·학원 평가(별점·체크 항목·리뷰 글)는 아래 리뷰 칸 안으로** 넣고, **구글 로그인한 사람만** 보게 한다. 로그인 안 하면 "리뷰 1건 · 로그인하면 볼 수 있어요"만 보임. 리뷰 칸 머리엔 "작성자들의 의견이며 이 사이트의 평가가 아님".
  - 좋은 점: 공표 범위가 좁아져 명예훼손 위험이 줄고, 구글 검색 결과에 평가가 뜨지 않음(학원 반발 감소). 가입이 늘어 다시 찾아올 사람이 생김.
  - 대가: 한 번 로그인해야 해서 Tokyo Jon(누구나 바로 읽음)보다 한 단계 늘어남. 구글 검색으로는 공개 자료만 잡힘.
- **리뷰 보기**: 별점 평균(작성자들의 의견) + 체크 항목 요약(예: "퇴직금 — 응답 4명 중 3명 '못 받음'") + 리뷰 글. 리뷰는 **1건부터 바로 공개**(사용자 결정 2026-11-26: 처음엔 거의 다 0건이라 3건 기준이면 사이트가 비어 보임). 리뷰가 적을 땐 "리뷰 1건 — 한 사람의 경험이에요"처럼 건수를 크게 보여 준다. 운영자가 붙이는 딱지("블랙리스트"·"위험")는 없음.
- **좋은 학원도 보인다**: 같은 항목에서 "다 받았음"이 많으면 그대로 보인다(그린리스트 효과, 학원에도 이득).
- **외부 검색 링크**: 레딧·Tokyo Jon·ESL Whitelist에서 같은 이름을 검색하는 링크(내용은 가져오지 않음).

### 가입 승인 (사용자 결정 2026-11-26)
- **구글 로그인 → 승인 질문 4개 → 운영자가 보고 승인** → 그다음에 리뷰 읽기·쓰기. 목적: 학원 원장·직원·리크루터 거르기.
- 질문: ① 지금 상황(한국에서 가르치는 중·가르쳤음·일자리 찾는 중·기타) ② 가르친 곳 종류(학원·공립·대학·기타) ③ 어떻게 알고 왔나(레딧·페이스북·친구·구글·기타) ④ "학원 원장·직원·리크루터가 아님" 확인(체크해야 제출) + 남길 말(선택, 300자).
- 거절되면 이유를 보여 주고 답을 고쳐 다시 신청. 운영자는 질문 없이 통과. 리뷰 **수**는 누구나, 내용·별점은 승인된 사람만.
- 대가: 승인될 때까지 기다려야 함 → 운영자가 하루 안에 처리하는 게 목표(운영 일이 생김).

### B. 리뷰 쓰기 (간단하게)
- **화면**(사용자 확인 2026-11-26, 그림): 한 화면에 위→아래 — 익명 안내 · 근무 연도(연도만) · 별점 2개(전체·원장, 필수) · 체크 5개(Yes/No/Not sure, 선택) · 경험 500자(선택, "이름·전화·담당 반·국적 쓰지 마세요") · 이 학원 다른 이름(선택) · 사실 확인 체크 · 올리기(언제든 고치기·지우기). 필수만 하면 30초.
- **근무 확인 사진은 첫 공개에서 뺌**(운영자 확인·즉시 삭제 일이 생김 → 나중에). **디자인은 나중에**(사용자 2026-11-26): 지금은 기능 화면 기본틀만.
- **별점 1~5 두 개: 전체 · 원장 태도**(사용자 결정 2026-11-26, 급여·숙소는 체크 항목이 다룸)와 짧은 글. 1~2분이면 끝.
- **근무 확인은 선택**: 계약서·급여명세서 사진을 내면 "근무 확인됨" 표시 → 운영자 확인 뒤 **사진 즉시 삭제**. 안 내도 리뷰는 쓸 수 있음(쉽게). 학원이 반론할 때 확인된 리뷰가 더 무게를 가짐.
- **체크 항목**(선택, **핵심 5개**, 사용자 결정 2026-11-26): 월급을 제때 받았나 · 퇴직금 받았나 · 4대보험 실제 납부됐나 · 계약대로 일했나(근무시간·숙소) · 이직동의서(LOR) 문제 있었나. 각각 예/아니오/모름 + 시기. 나머지(연차·계약서 바뀜(bait and switch)·마지막 월급 공제·리크루터 약속)는 글로.
- **짧은 글**(선택, 500자): 전화번호·이메일·링크는 자동으로 막는다. 사람 이름·욕설은 자동 차단 없이 **운영자가 매일 읽고 가림**(사용자 2026-11-27). 쓰기 전 "사실만 썼고 거짓이면 내 책임" 확인.
- **보복 막기**: 완전 익명(이메일만 받음), 1건부터 공개라 누가 썼는지 짐작되기 쉬움 → **재직 여부·퇴사일은 묻지도 저장하지도 않는다**(사용자 결정 2026-11-26: 개인정보이고 노출될 수 있음, '퇴사 뒤 공개' 기능 없음). 근무 시기는 **연도만**("2025"). 글에 자기를 알아볼 수 있는 내용(담당 반·국적 등)을 쓰지 말라고 쓰기 전에 안내.
- **고치기·지우기**(사용자 2026-11-26): 작성자는 언제든 지울 수 있고, 고칠 수도 있다(고치면 "Edited" 표시와 날짜).
- **신고 버튼**(사용자 2026-11-26): 다른 교사가 "이 리뷰 가짜 같아요"를 누르면 운영자 화면으로 → 삭제 요청과 같은 기준표로 처리. 학원 원장의 가짜 칭찬 리뷰를 교사들이 잡아 줌.

### C. 익명 게시판 Lounge (기획, 사용자 2026-11-27)
**한 줄**: 승인된 원어민 교사만 들어오는 익명 라운지. 학원 평가는 리뷰가, 게시판은 "나만 이런가?" 싶을 때 묻고 털어놓고 서로 답하는 곳.

- **누가**: 리뷰와 같이 로그인 + 승인 회원만 읽고 쓴다. 비회원은 "회원 전용 게시판이 있다" 안내만.
- **익명**: 글 안에서만 쓰는 번호(`OP`·`Anon 1`·`Anon 2`), 글마다 새로 매김. 프로필·"이 사람 글 모아 보기" 없음(글을 모으면 신원이 드러남). 시간은 "3시간 전"만, 지역은 선택·도 단위. 작성자 ID는 DB에만, 운영자만 본다. Anon 번호는 서버에서 계산해 실제 ID는 내려보내지 않는다.
- **칸**: Vent(털어놓기) · Ask(계약·퇴직금·비자·이직) · Life in Korea.
- **기능**: 글·댓글(답글 1단계) · 공감은 "Me too 🫂"만(싫어요 없음) · 작성자 언제든 고치기("Edited")·지우기(댓글 있으면 `[deleted]`) · 알림은 사이트 안 빨간 점만(메일 알림 보류) · **1:1 쪽지 없음**(괴롭힘·리크루터·신원 캐기 통로).
- **관리 = 자동 차단 대신 운영자가 매일 읽기**(사용자 2026-11-27, '바로 차단하기보다는 내가 매일 읽고 알아서 관리'):
  - 자동으로 막는 것은 리뷰에 이미 있는 **연락처(전화·이메일·링크)만**. 이름·욕설 자동 차단은 리뷰·게시판 모두 만들지 않는다.
  - 신고 버튼(이름 / 개인정보 / 괴롭힘·혐오 / 광고·리크루터 / 학원 쪽 사람 같음 / 기타)은 **운영자에게 알리기만**, 자동 숨김 없음.
  - 관리자 화면 **'게시판' 탭**: 지난번 읽은 뒤 새 글·댓글 목록(읽음 표시), 신고 붙은 것 위로, 가림·숨김·복구·회원 정지.
  - 판단은 리뷰와 같은 기준표: 이름·연락처·사생활 → 그 부분 가림 · 확인 안 된 범죄 단정 → 그 문장 가림 + 작성자 알림 · 경험·의견 → 유지 · 괴롭힘·혐오·다른 회원 공격 → 숨김 · 광고·구인·리크루터 → 숨김 + 정지 · 신원 캐기("OP 누구?") → 숨김. 정지는 경고 → 7일 → 영구. 초대 코드로 들어온 사람이면 초대 경로도 본다.
  - 도배 제한(하루 글 5·댓글 30)은 차단이 아니라 장치 보호용으로 둘지 미정.
- **DB**(Supabase 무료): `board_posts`·`board_comments`·`board_reactions`·`board_reports`, RLS는 승인 회원만 읽기·쓰기, 내 글만 수정.
- **정함**(사용자 2026-11-27): 이름 **Lounge** · **Hagwon talk 칸 없음**(학원 이야기는 리뷰로) · **위기 글 상담 전화 안내 넣지 않음** · 사이트 공개와 함께 말고 **회원이 모인 뒤 2단계로** 연다.

## 개발 명세 — 첫 공개: 학원 검색 + 리뷰 웹
**목표**: 리뷰 없이도 쓸모 있는 영어 학원 검색 사이트를 열고, 교사 커뮤니티 반응을 본다.

**만들 것**
1. **데이터 만들기 스크립트**(Python 표준 라이브러리, GitHub Actions 매달 실행, 결과를 저장소에 커밋)
   - 나이스 학원교습소정보: 개방포털 File 탭 최신 CSV. 다운로드 = `POST https://open.neis.go.kr/portal/data/file/downloadBlobFileData.do` (`infId=OPEN19220231012134453534385`, `infSeq=3`, `fileSeq=<최신 번호>`; 2026-10-31 파일은 `fileSeq=105`). 최신 번호는 File 탭 목록에서 찾는다. CP949.
   - 영어 학원 고르기: `학원교습소명=학원` 그리고 (`교습계열명`에 외국어 또는 `교습과정목록명`·`학원명`에 영어/어학). 학원지정번호로 중복 제거 → 약 1.7만 곳.
