# 원어민 교사 앱 기획 (사업장 확인 + 권리 도구)

상위: [[fair-work]]

## 한 줄
한국의 원어민 교사(E-2)가 **취업하기 전에 학원을 확인**하고(공식 자료 + 근무 인증된 체크 항목 후기), 일하는 동안엔 **계약서 점검·돈 계산·증거 기록·진정서 초안**으로 스스로를 지키는 영어 앱. 잡플래닛·블라인드의 안전장치를 따라 한다. 근거는 [[외국인 노동자 부당 대우 조사_261126]].

## 왜 원어민 교사부터
- 영어 하나로 된다(E-9는 10개+ 언어).
- 페이스북 그룹·레딧에 모여 있고, 블랙리스트 글이 이미 돌고 있다 = 수요가 있다.
- 기존 도구(Tokyo Jon·레딧)는 검색이 불편하고 검증이 없고, 잡플래닛·블라인드는 한국어·회사 이메일이라 못 쓴다.
- 언어교환 앱([[language-exchange]])의 첫 외국인 사용자와 같은 사람들 — 서로 소개할 수 있다.
- 나중에 같은 엔진으로 E-9 등 다른 외국인 노동자로 넓힌다(언어·비자 규칙만 바꿈).

| 정보 | 자유 글(검증 없음) | 익명 후기·공고 비교 | **정부 공개 숫자**(등록·폐원·국민연금 가입자·체불 명단) + 근무 인증 체크 항목 후기 |

- **한 줄 차별점**: "후기가 없어도 모든 학원을 확인할 수 있고, 문제가 생기면 그 자리에서 대응까지."
- **협력 가능성**: 경쟁하면서도 외부 검색 링크로 두 곳을 연결해 둔다(교사에게 이득, 우리 위험은 낮음). Tokyo Jon이 닫히면 그 사용자들이 옮겨 갈 곳이 되도록 1단계를 그 전에 연다.

## 기능

### A. 학원 확인 (구직 전)
- **검색**: 학원 이름·지역·사업자등록번호. 같은 사업자번호의 지점·바뀐 상호를 하나로 묶는다(기존 블랙리스트의 약점: 상호만 바꾸면 추적 불가).
- **공식 자료 칸**: 정부 공개 자료(체불 명단·국민연금 가입 사업장·학원 등록 상태)를 출처·날짜와 함께 그대로. 공개 기간이 끝나면 내린다. 아래 "공개 데이터".
- **후기 요약**: 서로 다른 근무 인증 후기가 **3건 이상**일 때만 숫자로 보여 준다. 예: "퇴직금 — 응답 4명 중 3명 '못 받음'". 운영자 평가·별점·"블랙리스트" 딱지 없음.
- **좋은 학원도 보인다**: 같은 항목에서 "다 받았음"이 많으면 그대로 보인다(그린리스트 효과, 학원에도 이득).
- **외부 검색 링크**: 레딧·Tokyo Jon·ESL Whitelist에서 같은 이름을 검색하는 링크(내용은 가져오지 않음).

### B. 후기 쓰기 (근무 인증)
- **근무 확인**: 계약서·급여명세서·외국인등록증의 근무처 중 하나를 사진으로 → 운영자가 확인 → **사진은 즉시 삭제**, "2026-12-01 계약서로 근무 확인" 기록만 남김.
- **체크 항목**(조사 TOP 10에 맞춤): 계약서대로 월급을 제때 받았나 · 퇴직금 받았나 · 4대보험 실제 납부됐나 · 근무시간이 계약과 같았나 · 연차를 내가 정해 썼나 · 숙소가 계약대로였나 · 이직동의서 문제 있었나 · 입국 전후 계약서가 같았나 · 마지막 월급에서 공제당했나 · 리크루터가 말한 조건과 같았나. 각각 예/아니오/모름 + 시기.
- **짧은 글**(선택, 500자): 사람 이름·전화번호·욕설은 자동으로 막는다. 쓰기 전 "사실만 썼고 거짓이면 내 책임" 확인.
- **보복 막기**: 완전 익명(이메일만 받음), **퇴사 뒤 공개** 기본값, 근무 시기는 "2025년 하반기"처럼 흐리게, 후기가 3건 모일 때까지 안 보임.

### C. 권리 도구 (로그인 없이, 기기 안에서만)
agy 제안 TOP 5를 그대로 받음([[외국인 노동자 부당 대우 조사_261126#5-1. agy가 제안한 0원 기능 TOP 5 (원어민 교사)|조사 5-1]]).
1. **계약서 점검기**: PDF를 브라우저 안에서 읽어 위험 조항 30개를 찾고 법 설명 + 고쳐 달라는 영·한 문구.
2. **돈 계산기**: 퇴직금·지연이자·4대보험 정상 공제·미사용 연차·국민연금 반환 가능 여부(국적별), 5인 미만 규칙 반영.
3. **진정서 초안**: 영어로 고르면 노동청 제출용 한국어 진정서 + 원장에게 보낼 한국어 문자.
4. **증거 금고**: 출퇴근 원탭 기록, 입주 숙소 사진 체크리스트, 퇴사일 → D+14·D+15 캘린더 파일. 기기 안에만 저장, 내보내기로 묶음 PDF.
5. **도움 연락처**: 1350(영어), 1345, 132, ai.moel.go.kr, 노조·LOFT.

도구는 서버에 아무것도 보내지 않는다 → 운영비·개인정보 위험이 거의 없다.

### 국민연금 데이터 시험 결과 (2026-11-26, 2026-10 기준 파일 115MB)
- **받기**: 공공데이터포털에서 로그인·보안문자 없이 받아짐(CP949 CSV). GitHub Actions로 매달 자동으로 받을 수 있다.
- **크기**: 58.8만 사업장. **등록 사업장은 모두 가입자 3명 이상**(1~2명은 0곳) → **가입자 1~2명인 작은 사업장은 목록에 아예 없다**(개인정보 때문으로 보임). 탈퇴 사업장은 가입자 0으로 남아 있음.
- **사업자번호는 앞 6자리만**, 주소는 **도로명까지만**(건물 번호 없음) → 사업자번호로 정확히 맞출 수 없다. 이름 + 시군구 + 도로명으로 맞춰야 함.
- **학원 찾기**: 업종 "일반 교과학원" 2,509 · "외국어학원" 307 등. 이름에 영어·어학원이 들어간 학원 후보 **776곳**(등록 680·탈퇴 96, 가입자 10명+ 380 · 5~9명 160 · 3~4명 138).
- **알려진 학원 찾기**: 정상어학원 지점들·이보영의 토킹클럽·ECC·YBM·최선어학원·아발론·렉스김 등 **찾아짐**. 대신 이름이 지저분하다(법인명+지점명, 전각 괄호, 같은 브랜드도 따로따로, 업종이 "도서 도매업"처럼 엉뚱하게 붙은 곳도 있음).
- **체불 명단 교육 업체 7곳과 대조**: 1곳만 찾음(나머지는 폐업·이름 다름·3명 미만 중 무엇인지 모름).
- **결론**:
  - 영어 학원 776곳은 전국 영어 학원 수보다 훨씬 적다 → **"목록에 없음"은 4대보험 미가입의 증거가 아니다**(가입자 1~2명이거나 이름이 다를 수 있음). 화면에선 "3명 이상 가입한 사업장 공개 목록에서 찾지 못했어요. 작은 곳이거나 이름이 다를 수 있어요 → 직접 확인할 질문"으로만.
  - **찾아졌을 때 쓸모가 크다**: 가입자 수(3~4명이면 5인 미만), 매달 신규·상실 수(사람이 자주 바뀌는지), 탈퇴 여부.
  - **바탕 목록은 나이스 학원 정보로**(등록된 학원 전체) 만들고, 국민연금은 그 위에 겹치는 정보로.

### 나이스 학원 정보 시험 결과 (2026-11-26, 2026-10-31 기준 파일 36MB)
- **받기**: 나이스 교육정보 개방포털 "학원교습소정보" File 탭에서 **매달 CSV**(2021-01부터 전부), 로그인 없이 받아짐(CP949). Open API는 인증키 없이 5건까지만 → 전체는 파일로. 이용허락범위 제한 없음.
- **크기**: 13.8만 곳(학원 9.5만·교습소 4.3만), 모두 "개원"(폐원한 곳은 빠짐 → **지난달 파일과 비교해야 폐원을 알 수 있음**).
- **열**: 학원지정번호(고유 번호)·학원명·개설일자·등록일자·정원·분야·교습계열·교습과정·인당 수강료·**도로명주소(건물 번호까지)**·전화번호. 대표자 이름은 이 파일에 없음.
- **영어 관련 학원**(교습계열 외국어 또는 과정·이름에 영어/어학): **17,251곳**(경기 5,982·서울 2,611·경남·부산·대구 순).
- **국민연금과 맞추기**: 이름 + 시군구로 **483곳(2.8%)만** 맞음(도로명까지 일치 444). 국민연금의 교육 업종 등록 사업장은 전국 6,226곳뿐 → **대부분의 학원은 가입자가 3명 미만이라 국민연금 공개 목록에 없다**. 이름이 달라서(법인명·대표자 이름으로 등록) 못 맞춘 것도 섞여 있음.
- **결론**:
  - **검색의 바탕 = 나이스**(영어 학원 1.7만 곳, 지정번호·정확한 주소). 교사가 계약서의 학원 이름·주소로 바로 찾을 수 있다.
  - 나이스만으로도 보여 줄 수 있는 사실: 정식 등록 학원인지(목록에 없으면 "교육청 등록 목록에서 찾지 못함 → 확인할 질문"), 개설일, 정원, 지난달 대비 폐원·같은 주소 새 학원(**상호 바꾸기 추적**).
  - 국민연금은 맞는 3% 정도에만 겹쳐 보여 줌(큰 학원·체인). 작은 학원엔 "공개 기준(3명 이상) 밖" 안내.
  - 학원 후기(3단계)가 생기면 나이스 지정번호에 붙인다 → 이름 바뀌어도 같은 학원으로 묶임.

### 우회해서 쓸 수 있는 신호 (후기 없이)
- **"이 학원은 국민연금 가입 사업장인가?"** — ②에서 '탈퇴'면 확인 질문을 붙임. **없다고 미가입은 아님**(3명 미만은 공개 안 됨, 아래 시험 결과). 3.3% 위장 프리랜서 문제 #1과 연결. 교사는 자기 연금 납부를 국민연금 앱·1355로 직접 확인할 수 있다고 함께 안내.
- **가입자 수** — 5인 미만이면 부당해고 구제·연차·가산수당이 없다는 것을 계약 전에 알려 줌(계산기와 연결).
- **상실자 수 ÷ 가입자 수(이직률)** — 매달 사람이 많이 나가는 곳 표시. 숫자만 보여 주고 해석은 사용자가.
- **고지금액 ÷ 가입자 수** — 1인당 신고 소득이 이상하게 낮으면 급여를 낮춰 신고했을 가능성(해석 주의, 판단은 안 함).
- **폐업 → 같은 주소 새 상호** — ③·④로 상호 변경을 묶어서 보여 줌(기존 블랙리스트의 약점 보완).
- **체불 명단** — 학원은 적지만, 리크루터·관련 법인 확인용으로도 씀.

> 모두 정부가 공개한 숫자라 "사실 그대로 + 출처·날짜 표시"면 위험이 낮다. 다만 "이직률 높음 = 나쁜 학원"처럼 **앱이 해석을 붙이지 않는다**. 1단계(도구) 때 함께 공개할 수 있다.
> 만드는 법: GitHub Actions(무료)로 매달 ②·③ CSV를 받아 학원(교육 서비스업)만 골라 작은 JSON으로 만들어 정적 페이지에 싣는다. 서버 없음.

## 표시 원칙 (법에 걸리지 않게 보여 주는 법, 2026-11-26 조사, 법률 자문 아님)
**가리는 방식은 효과가 없다**: 초성("ㅇㅇ어학원")·이니셜로 써도 지역·업종으로 알아볼 수 있으면 명예훼손의 "특정성"이 인정된다(대법원 2005도10132 취지, 로톡 변호사 글들). 앱도 쓸모없어진다. → 숨기지 말고 **"사실 + 공익 + 비방 목적 없음"이 드러나게 보여 준다**. 판단 요소는 내용·성질·공표 범위·**표현 방법**(대법원 2010도10864). 중요한 부분이 사실이면 세부가 조금 달라도 허위가 아니고, 허위 인식은 검사가 증명한다. 산후조리원 이용 후기를 비방 목적이 없다고 본 대법원 판결(2012)도 있다.

1. **사실만, 출처·기준일과 함께**: "국민연금 가입 사업장 내역(2026-10 기준)에서 찾지 못함", "고용노동부 체불 사업주 명단(2026년 1차)에 있음". 숫자·원문 그대로.
2. **딱지·해석·별점 없음**: "악덕", "블랙리스트", "위험 학원", 빨간 경고 아이콘 쓰지 않음. 색도 중립(회색·파랑).
3. **비난 대신 "확인할 질문"으로**: 신호마다 계약 전에 물어볼 질문을 붙인다. 예: 국민연금에서 못 찾음 → "4대보험에 가입해 주나요? 가입 증명을 보여 줄 수 있나요?" / 가입자 4명 → "5인 미만 사업장은 연차·가산수당이 법 의무가 아닙니다. 계약서에 적혀 있나요?" — 사실을 알려 주고 구직자가 스스로 확인하게 하는 구조(공익 목적이 드러남).
4. **검색했을 때만 보여 줌**: "나쁜 학원 순위", "이번 달 신고 많은 곳" 같은 목록·순위·지도 핀·SNS 공유 카드는 만들지 않는다(공표 범위·표현 방법을 좁힘). 공유는 앱 소개만.
5. **비교 기준을 같이**: 이직 숫자를 보여 줄 땐 "같은 지역 교육 서비스업 평균"을 함께 — 공정하게 보이고 오해를 줄임.
6. **정확하게 맞을 때만**: 사업자번호(또는 이름 + 주소)가 맞을 때만 표시. 이름만 비슷하면 표시하지 않거나 "같은 곳인지 확인되지 않음". 잘못 붙이면 그게 곧 허위 사실이다(가장 현실적인 위험).
7. **사람 이름·나이는 빼고 상호만**: 체불 명단엔 사업주 이름·나이가 있지만 앱엔 싣지 않는다(개인정보 최소화, 목적에 필요 없음).
8. **기간이 끝나면 내림**: 체불 명단 3년 공개가 끝나면 자동으로 삭제, 국민연금은 최신 달만.
9. **학원 설명란**: 학원이 "이 정보에 대한 설명"을 남길 수 있게(사업자 확인 뒤). 정정 요청이 오면 원문 자료를 다시 대조하고 기록.
10. **화면에 목적 문구**: "구직자가 계약 전에 확인할 수 있도록 정부 공개 자료를 보여 줍니다. 학원을 평가하지 않습니다." — 면책은 아니지만 공익 목적의 근거가 된다.

## 법적 안전장치 (잡플래닛·블라인드 방식, 법률 자문 아님)
| 위험 | 장치 |
|---|---|
| 명예훼손(운영자 방조) | 운영자는 판단하지 않음(딱지·별점·"악덕" 없음), 숫자 사실만, 3건 이상, 글 고쳐 쓰지 않음, 특정 학원 따로 강조 안 함 |
| 명예훼손(작성자) | 체크 항목 위주, 사실 확인 서약, 이름·욕설 차단 → 사실 + 공익(구직자 정보) 구조 |
| 업무방해(거짓 정보) | 근무 인증, 한 사람 1학원 1후기, 3건 이상 |
| 임시조치 의무 | 학원용 **삭제·반론 요청 양식** → 바로 30일 가리기 → 작성자에게 알림 → 학원 반론 같이 싣기 → 처리 기록 전부 보관 |
| 개인정보 | 인증 사진 즉시 삭제, 이메일 외 신원 정보 없음 → 내줄 것도, 샐 것도 없음 |
| 공식 자료 | 출처·공개일 표시, 원문 그대로, 기간 끝나면 내림 |

- 이름에 "Blacklist" 같은 말을 쓰지 않는다.
- 출시 전 **무료 법률 검토**(대한법률구조공단 132, 마을변호사, 스타트업 무료 법률 지원)로 약관·삭제 절차·화면 문구를 본다.
- 고소 자체는 막을 수 없다. 절차를 지켰다는 기록이 무혐의의 근거가 된다.
- 사용자 후기를 무료 제미나이 키 등 외부 AI로 보내지 않는다.

## 단계
1. **도구 + 공개 데이터 (위험 가장 낮음)**: C의 1·2·5 + A의 외부 검색 링크 + **학원 검색(국민연금 가입·가입자 수·이직 숫자, 체불 명단)**. 정적 웹(GitHub Pages), 로그인 없음. 원어민 교사 페이스북 그룹·레딧에 공유 → 반응 확인.
2. **증거 금고·진정서 초안** 추가(C의 3·4).
3. **법률 검토 → 후기 열기**: B + A 요약. Supabase(무료) + 구글 로그인 또는 이메일. 처음엔 서울·경기 학원만.
4. **다른 외국인 노동자로 넓히기**: 같은 엔진에 언어·비자 규칙 추가(E-9부터, 베트남어·네팔어 등).

## 0원 구조
- 1~2단계: 정적 페이지 + 브라우저 저장(IndexedDB). 서버 없음.
- 3단계: Supabase 무료(후기·요청 기록), 인증 사진은 비공개 버킷에 올렸다가 확인 즉시 삭제.
- 외부 AI 없음. 계약서 점검은 규칙(정규식·키워드)으로.

## 성공 지표
- 1단계: 공유 뒤 2주 동안 계산기·점검기 사용 수, 그룹 반응(저장·공유).
- 3단계: 첫 달 인증 후기 수, 3건 넘은 학원 수, 삭제 요청 수와 처리 기간.

## 위험
- **고소**: 위 장치 + 법률 검토. 1인 운영의 스트레스는 남는다.
- **후기가 안 모임**(보복 두려움) → 퇴사 뒤 공개·흐린 시기·3건 모일 때까지 숨김.
- **거짓 후기·학원의 좋은 후기 조작** → 근무 인증, 한 사람 1학원 1후기.
- **법 정보가 틀림** → 계산기마다 근거 조항과 "참고용, 노동청·노무사 확인" 표시, 법 개정(최저임금·연금 요율) 해마다 갱신.
