# 🇯🇵 일본 확장 검토 (원어민 교사)

상위: [[fair-work]] · 한국판: [[원어민 교사 앱 기획_261126]]

**결론**: 일본으로 넓힐 수는 있다. 하지만 지금은 하지 않는다. 일본은 문제의 모양이 한국과 다르다. 한국은 **작은 학원 2만 곳**이 문제고, 일본은 **큰 회사 몇 곳의 고용 방식**이 문제다. 그래서 한국판을 그대로 옮기면 안 되고 화면을 회사 중심으로 바꿔야 한다. 한국판이 자리 잡은 뒤(리뷰가 쌓이고 운영이 안정된 뒤) 다시 본다(2026-11-27부터 Midnight Run Korea에 집중).

## 1. 일본 원어민 교사는 어디서 일하나
| 종류 | 설명 | 대표 회사 |
|---|---|---|
| **JET** | 정부 프로그램. 지자체가 직접 고용. 대체로 조건이 좋다 | — |
| **ALT 파견(派遣)·청부(請負) 회사** | 회사가 교사를 고용해 공립학교에 보낸다. **문제가 가장 많은 곳** | Interac, Altia, BorderLink, Heart, JoyTalk 등 |
| **에이카이와(英会話)** | 사설 영어 회화 학원. 한국 학원과 가장 비슷하다 | AEON, ECC, NOVA, Gaba, Berlitz |
| 직접 고용 | 지자체·사립학교가 직접 고용. 일본어가 필요한 경우가 많다 | — |

- 공립 중학교 ALT는 약 7,900명이고, 그중 JET이 28.5%다(MEXT 조사, 조사 연도 미확인). 전체 ALT 수의 최신 공식 숫자는 못 찾음(미확인).

## 2. 자주 나오는 문제 (한국과 비교)
| 문제 | 일본 | 한국 |
|---|---|---|
| 사회보험 빼기 | **가장 큰 문제.** 근무 시간을 기준선 바로 아래로 맞춰 사회보험(건강보험·후생연금)에 넣지 않는 일. 2026-06 Interac 상대 사회보험 소송 첫 재판(도쿄지법, General Union) | 국민연금·4대보험 미가입 |
| 위장 청부(偽装請負) | 청부 계약인데 학교가 직접 지시한다. 문부과학성도 지침을 냈다 | 거의 없음 |
| 짧은 계약·재계약 불안 | 1년 계약, 학교에서 불만이 나오면 재계약을 안 해 줌 | 비슷 |
| 업무위탁(개인사업자) 계약 | 일부 에이카이와가 교사를 직원이 아닌 개인사업자로 계약(Gaba·NOVA 사례 보도) | 프리랜서 계약 일부 |
| 월급 체불·야반도주 | 한국보다 적다. NOVA 파산(2007) 같은 큰 사건은 있었다 | **가장 큰 문제**(midnight run) |
| 퇴직금 | 법적 의무가 없다 → 분쟁이 적다 | 1년 이상이면 의무, 분쟁이 많다 |

→ 일본판의 핵심 질문은 "월급이 나오나"보다 **"사회보험에 넣어 주나, 계약이 안정적인가"**다.

## 3. 교사들이 이야기하는 곳 (2026-11-27 다시 조사)
처음엔 "모은 곳이 없다"고만 썼다. 사용자 지적("내가 아는 원어민들은 일본에서 힘들어했다, 이야기하는 곳이 있을 것")으로 다시 찾았다. **이야기하는 곳은 많다. 다만 Tokyo Jon처럼 회사별로 한곳에 모은 사이트가 지금은 없다.** 비슷한 곳은 있었지만 닫혔다.

## 4. 한국판 "공개 자료 칸"에 해당하는 일본 공식 자료
| 한국판 | 일본 대응 | 쓸 수 있나 |
|---|---|---|
| 나이스 학원 등록(2만 곳) | **없음.** 에이카이와는 등록 의무가 없다. 대신 **법인번호 공표 사이트**(국세청, 모든 법인)로 회사 목록을 만든다 | 법인번호는 공개 자료, Web-API 있음(신청 필요, 무료인지 미확인) |
| 국민연금 가입 사업장 | **후생연금·건강보험 적용 사업소 검색**(일본연금기구). 회사명·법인번호로 누구나 검색. 지금 가입했는지, 2년 안에 탈퇴했는지 보인다 | 화면 검색만 있음. 한꺼번에 내려받기는 없고, 자동 수집이 허용되는지 미확인 |
| 체불 명단 | **노동기준 관계 법령 위반 공표 사안**(후생노동성, 매달 PDF). 회사명·위반 조항·내용 | PDF로 공개. 다만 건설·안전 위반이 대부분이라 교육 회사는 드물 것 |
| — | **파견업 허가 명단**(인재서비스 종합 사이트, 후생노동성). ALT 파견 회사가 허가를 받았는지, 행정처분을 받았는지 | 화면 검색으로 공개 |

- 주의: 적용 사업소 검색은 **회사가** 사회보험에 들었는지만 보여 준다. **교사 개인을** 넣어 줬는지는 모른다. 회사는 가입했는데 시간을 맞춰 교사만 빼는 게 일본에서 흔한 수법이다 → 이 칸은 리뷰의 체크 항목("사회보험에 넣어 줬나")이 채워야 한다.

## 5. 일본판을 만든다면 바꿀 점
1. **회사 중심 화면**: 회사(Interac 등) → 지사·파견 지역으로 내려가는 구조. 학원 지도는 에이카이와 체인 교실에만.
2. **체크 항목 바꾸기**: 사회보험 가입 / 주 근무 시간(29.5시간 같은 쪼개기) / 계약 형태(고용·업무위탁) / 재계약 / 교통비·휴가. 퇴직금은 뺀다.
3. **JET과 비교 칸**: 같은 지역 JET 조건과 비교하면 쓸모가 크다(미확인 아이디어).
4. **법적 위험 다시 보기(미확인, 전문가 확인 필요)**: 일본은 공익 목적이고 사실이면 명예훼손 책임을 면할 길이 있어(형법 230조의2) 한국보다 나을 수 있다. 하지만 **발신자 정보 공개 청구**가 흔하다. 회사가 법원을 통해 리뷰 쓴 사람의 정보를 요구할 수 있으니 우리가 가진 회원 정보(구글 계정 등)를 최소로 해야 한다. 2025년부터는 큰 플랫폼에 정보유통플랫폼대처법 의무가 생겼다(우리 규모에 해당하는지 미확인).
5. **같은 코드로**: 언어는 영어 그대로다. 공개 자료 수집기와 체크 항목만 나라별로 갈아 끼우면 된다. 기획에 적어 둔 "같은 엔진으로 다른 나라·비자로 넓힌다"와 맞다.
