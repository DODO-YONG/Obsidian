# ⚖️ fair-work — 외국인 노동자 사업장 평가·리뷰 앱 (기획)

상위: [[00_홈]]

노동자가 사업장 **평가·리뷰를 남기고 취업 전에 쉽게 확인**하는 앱. 첫 대상은 한국의 원어민 교사(E-2, 학원). 이름·코드명 미정.

- **조사**: [[외국인 노동자 부당 대우 조사_261126]] — 원어민 교사 문제 TOP 10, 해결 경로와 한계, 기존 도구, 법적 핵심, 다른 외국인 노동자
- **기획서**: [[원어민 교사 앱 기획_261126]] — 학원 검색·평가·리뷰, 공개 데이터, 표시 원칙, 잡플래닛식 법적 안전장치, 단계

## 설계 결정
- **출발**(2026-11-26): 언어교환 앱 이야기 중 사용자가 "원어민 교사들이 학원에서 부당한 대우를 많이 받는다" → 이 문제를 푸는 앱을 만들기로. 다른 외국인 노동자도 같은 문제가 있으니 넓힐 수 있게.
- **사업장 후기는 하되 잡플래닛·블라인드 방식 안전장치로**(사용자 결정): 3건 이상 공개, 운영자 판단 없음, 삭제·반론 절차, 근무 확인은 선택. agy는 후기 게시판을 피하라고 했지만, 순서를 **학원 검색 먼저 → 무료 법률 검토 → 리뷰**로 나눠 위험을 낮춤.
- **원어민 교사부터, 같은 엔진으로 E-9 등으로 확장.**
- **범위 줄임**(사용자 2026-11-26): 계약서 점검·계산기·진정서 같은 권리 도구는 부담돼서 빼고, **학원 검색 + 평가·리뷰**만.
- **웹 먼저, 앱은 나중**(사용자 2026-11-26): 검색·링크 공유로 찾아오는 서비스라 웹이 맞고, Play 사용자 글 정책 위험도 피함. 1단계 학원 검색 웹은 다른 세션에서 개발 시작 — 명세는 [[원어민 교사 앱 기획_261126#개발 명세 — 1단계 학원 검색 웹 (다른 세션에서 개발 시작)|기획서 개발 명세]].
