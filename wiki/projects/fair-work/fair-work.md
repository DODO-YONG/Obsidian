# ⚖️ fair-work — 외국인 노동자 사업장 평가·리뷰 앱 (기획)

상위: [[00_홈]]

노동자가 사업장 **평가·리뷰를 남기고 취업 전에 쉽게 확인**하는 앱. 첫 대상은 한국의 원어민 교사(E-2, 학원). 이름 **Midnight Run Korea**, 코드명 **DY-010 LOOKOUT**.

- **조사**: [[외국인 노동자 부당 대우 조사_261126]] — 원어민 교사 문제 TOP 10, 해결 경로와 한계, 기존 도구, 법적 핵심, 다른 외국인 노동자
- **잡플래닛·잡코리아 분석**: [[경쟁 사이트 분석_잡플래닛·잡코리아_261127]] — 리뷰 양식·열람·면접 후기·안전장치 비교, 가져올 것 고르기
- **기획서**: [[원어민 교사 앱 기획_261126]] — 학원 검색·평가·리뷰, 공개 데이터, 표시 원칙, 잡플래닛식 법적 안전장치, 단계

## 설계 결정
- **출발**(2026-11-26): 언어교환 앱 이야기 중 사용자가 "원어민 교사들이 학원에서 부당한 대우를 많이 받는다" → 이 문제를 푸는 앱을 만들기로. 다른 외국인 노동자도 같은 문제가 있으니 넓힐 수 있게.
- **사업장 후기는 하되 잡플래닛·블라인드 방식 안전장치로**(사용자 결정): 3건 이상 공개(→ 아래 '1건부터'로 바뀜), 운영자 판단 없음, 삭제·반론 절차, 근무 확인은 선택. agy는 후기 게시판을 피하라고 했지만, 순서를 **학원 검색 먼저 → 무료 법률 검토 → 리뷰**로 나눠 위험을 낮춤(→ 아래 '리뷰 처음부터'로 바뀜).
- **원어민 교사부터, 같은 엔진으로 E-9 등으로 확장.**
- **범위 줄임**(사용자 2026-11-26): 계약서 점검·계산기·진정서 같은 권리 도구는 부담돼서 빼고, **학원 검색 + 평가·리뷰**만.
- **웹 먼저, 앱은 나중**(사용자 2026-11-26): 검색·링크 공유로 찾아오는 서비스라 웹이 맞고, Play 사용자 글 정책 위험도 피함. 개발 명세는 [[원어민 교사 앱 기획_261126#개발 명세 — 첫 공개: 학원 검색 + 리뷰 웹|기획서 개발 명세]].
- **리뷰 처음부터, 법률 검토 없음**(사용자 2026-11-26): 검색만 먼저 → 법률 검토 → 리뷰 순서를 없애고, 첫 공개에 검색 + 리뷰를 함께 연다. 위험은 기본 장치(출처 그대로·딱지 없음·리뷰 건수 크게 표시·이름·욕설 차단·삭제 요청 창구)로 줄인다.
- **이름 Midnight Run Korea**(사용자 2026-11-26): 원어민 교사 은어 'midnight run'(계약을 못 버티고 밤에 몰래 출국) + Korea. 'Midnight Run'만으로는 1988년 영화·뉴욕 노숙인 지원 단체(midnightrun.org)·달리기 대회와 겹쳐서 Korea를 붙임. midnightrunkorea.com·midnightrunkorea.vercel.app 비어 있음(2026-11-26 확인). 'hagwon'·'blacklist'는 쓰지 않음. 소개 문구는 'Avoid the midnight run — check before you sign'처럼 **도망칠 일을 막는 곳**으로(계약 위반을 부추기는 인상 피함). 상표 등록은 확인 안 함.
- **코드명 DY-010 LOOKOUT**(사용자 2026-11-26): 망보는 사람 — 계약 전에 미리 알려 줘서 runner가 안 생기게. RUNNER도 마음에 들었지만 목적(도망을 막는 것)과 반대 뜻이라 뺌. DY-009는 언어교환 앱 몫.
- **운영 방식**(사용자 2026-11-26): 삭제·정정 요청은 사이트 안 양식 + 사이트용 새 Gmail(개인 메일 숨김) · 당분간 완전 무료(광고·학원 돈 없음) · 코드는 새 비공개 저장소 `DODO-YONG/midnight-run-korea` + Vercel 무료.
- **기획 다듬기**(사용자 2026-11-26): 영어 검색 = 자동 로마자 + 체인 영어 이름 표 + 교사가 영어 이름 추가 · 리뷰 **1건부터 공개**(3건 기준이면 처음에 텅 빔, 대신 건수 크게) · 가짜 리뷰 = 구글 로그인 + 학원당 1건 + 새 계정 몰림 알림. 홍보 채널은 미정.
- **기획 다듬기 2**(사용자 2026-11-26): 체크 항목 핵심 5개(월급·퇴직금·4대보험·계약대로 근무·LOR) · 삭제 요청은 **운영자가 기준표로 보고 결정**(이름·욕설 가림, 범죄 단정은 문장만, 경험·의견은 유지 + 반론) · 대상은 학원만(EPIK 제외) · 공개 전 아는 교사 5~10명에게 첫 리뷰 부탁.
- **기획 다듬기 3**(사용자 2026-11-26): 별점은 전체 + 원장 태도 2개 · **재직 여부·퇴사일은 받지 않음**(개인정보, 노출 위험 → '퇴사 뒤 공개' 없앰, 근무 시기는 연도만) · 폐원 뒤 같은 주소 새 학원은 연결 안 함 · 학원 설명·반론은 양식으로만(학원 계정은 나중).
- **기획 다듬기 4**(사용자 2026-11-26): 국민연금은 가입 여부·가입자 수·들고 남만(1인당 고지금액 뺌) · 작성자는 언제든 지우기·고치기("Edited" 표시) · 교사용 '가짜 같아요' 신고 버튼 · 통계는 Vercel 무료(쿠키 없음).
- **평가는 안쪽 + 로그인한 사람만**(사용자 2026-11-26, 화면 그림 확인): 학원 페이지 위엔 사실(공개 자료·확인할 질문)만, 원장·학원 별점·체크 항목·리뷰 글은 아래 리뷰 칸 안, 구글 로그인해야 보임. 공표 범위를 좁혀 위험을 낮춤, 대신 읽기 전에 로그인 한 번.
- **개발 시작**(2026-11-26): 비공개 저장소 `DODO-YONG/midnight-run-korea`에 기본틀(데이터·화면·DB·지도). 지도는 같은 색 핀 + 리뷰 수·별점(로그인). 현황은 [[원어민 교사 앱 기획_261126#개발 현황|기획서 개발 현황]].
- **가입 승인제**(사용자 2026-11-26): 구글 로그인 → 승인 질문 4개 → 운영자 승인 뒤 리뷰 읽기·쓰기. 학원 쪽 사람 거르기. DB·화면·운영자 화면 완료, Supabase 적용.
- **신분 안전·가짜 차단 1단계**(사용자 2026-11-26): 여권·ARC·실명·입퇴사일 수집 0을 가입 화면에 명시 + 승인 교사 **1인 3회 초대 코드**(`invite_codes`, 즉시 승인·악용 시 연쇄 추적) + 초대 코드 없는 신청자는 **영문 1~2문장 맥락 질문** + 관리자 화면 전용 **브라우저 언어(`browser_lang`) 참고 배지**(자동 차단 없음). DB 패치·시험 완료. Claude 검토 뒤 보강(2026-11-26): 거절된 사람은 초대 코드로 우회 못 함, 초대받은 사람은 리뷰 1건 또는 30일 뒤부터 초대, 코드 10자리, 가입·관리자 화면 반영.
- **배포 전 결정**(사용자 2026-11-26): Tokyo Jon 글은 **아직 안 보여 줌**(시드 적용 안 함 → **2026-11-27 바꿈: 승인 회원에게 글자로 보여 줌**) · 초대받은 사람은 **리뷰 1건 또는 30일 뒤** 초대 가능 · 가입 질문 중 **비자/상태(종류만)·영어 맥락 답 둘 다 필수**(초대 코드 없을 때) · **지금 배포, 레딧 등 공개는 사이트용 Gmail·구글 로그인 공개 전환 뒤**(그 사이 아는 교사 5~10명으로 첫 리뷰).
- **흐름: 먼저 검색, 리뷰 볼 때 가입**(사용자 2026-11-26): 검색·공개 자료·지역 둘러보기는 로그인 없이, 리뷰 내용만 로그인+승인. 홈에 가입 안내 한 줄과 머리말 Sign in.
- **이름 뜻을 화면에**(사용자 2026-11-26, '이름만 보면 도망가라는 것 같다'): 홈 검색 위·학원 페이지 공개 자료 위에 'midnight run은 밤에 떠나야 할 만큼 몰리는 것, 이 사이트는 그렇게 되지 않게 계약 전에 확인하는 곳' 안내(노란 달 표시), 소개 페이지에 'Why “Midnight Run”?' 절. 법적 설명·공식 도움 안내는 넣지 않음(사용자: '그게 제대로 작동하면 이런 사이트가 필요 없다').
- **초대 링크 한도**(사용자 2026-11-26): 1인 3개는 **살아 있는 링크**(안 쓴 것 + 그 링크로 가입한 것)만 셈, 안 쓴 링크는 취소하면 자리가 돌아옴. 한 링크 한 사람, 단톡방 말고 1:1 메시지·메일로 보내라고 초대 화면에 안내.
- **건의사항 받기**(사용자 2026-11-26): Feedback 페이지(제안·오류·빠진 학원·기타, 메일은 선택), 로그인 없이 보낼 수 있고 운영자만 읽음(관리자 '건의사항' 탭), 도배 제한. 검색 결과 없음·학원 페이지에서 '알려 주세요'로 연결.
- **남은 기능 정리**(사용자 2026-11-27): **리크루터는 안 다룸**(후기 대상·리뷰 칸 모두 없음 — 오로지 원어민 교사가 자기 생각을 적는 곳) · **홍보는 사이트가 완성된 뒤** · 브랜드 배지 = 체인 62개 **중립색 글자 모노그램**(브랜드 고유 색 안 따라 함, 공식 로고는 학원이 직접 보낸 경우만), 목록·학원 페이지 머리에만 · **근무 확인 사진 안 함** · 관심 학원 새 리뷰 알림 **보류** · **학원 계정 안 만듦**(학원 설명·반론은 양식으로만).
