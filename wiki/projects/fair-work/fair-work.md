# ⚖️ fair-work — 외국인 노동자 사업장 평가·리뷰 앱 (기획)

상위: [[00_홈]]

노동자가 사업장 **평가·리뷰를 남기고 취업 전에 쉽게 확인**하는 앱. 첫 대상은 한국의 원어민 교사(E-2, 학원). 이름 **Midnight Run Korea**, 코드명 **DY-010 LOOKOUT**.

- **조사**: [[외국인 노동자 부당 대우 조사_261126]] — 원어민 교사 문제 TOP 10, 해결 경로와 한계, 기존 도구, 법적 핵심, 다른 외국인 노동자
- **기획서**: [[원어민 교사 앱 기획_261126]] — 학원 검색·평가·리뷰, 공개 데이터, 표시 원칙, 잡플래닛식 법적 안전장치, 단계

## 설계 결정
- **출발**(2026-11-26): 언어교환 앱 이야기 중 사용자가 "원어민 교사들이 학원에서 부당한 대우를 많이 받는다" → 이 문제를 푸는 앱을 만들기로. 다른 외국인 노동자도 같은 문제가 있으니 넓힐 수 있게.
- **사업장 후기는 하되 잡플래닛·블라인드 방식 안전장치로**(사용자 결정): 3건 이상 공개(→ 아래 '1건부터'로 바뀜), 운영자 판단 없음, 삭제·반론 절차, 근무 확인은 선택. agy는 후기 게시판을 피하라고 했지만, 순서를 **학원 검색 먼저 → 무료 법률 검토 → 리뷰**로 나눠 위험을 낮춤(→ 아래 '리뷰 처음부터'로 바뀜).
- **원어민 교사부터, 같은 엔진으로 E-9 등으로 확장.**
- **범위 줄임**(사용자 2026-11-26): 계약서 점검·계산기·진정서 같은 권리 도구는 부담돼서 빼고, **학원 검색 + 평가·리뷰**만.
- **웹 먼저, 앱은 나중**(사용자 2026-11-26): 검색·링크 공유로 찾아오는 서비스라 웹이 맞고, Play 사용자 글 정책 위험도 피함. 개발 명세는 [[원어민 교사 앱 기획_261126#개발 명세 — 첫 공개: 학원 검색 + 리뷰 웹|기획서 개발 명세]].
- **리뷰 처음부터, 법률 검토 없음**(사용자 2026-11-26): 검색만 먼저 → 법률 검토 → 리뷰 순서를 없애고, 첫 공개에 검색 + 리뷰를 함께 연다. 위험은 기본 장치(출처 그대로·딱지 없음·리뷰 건수 크게 표시·이름·욕설 차단·삭제 요청 창구)로 줄인다.
- **이름 Midnight Run Korea**(사용자 2026-11-26): 원어민 교사 은어 'midnight run'(계약을 못 버티고 밤에 몰래 출국) + Korea. 'Midnight Run'만으로는 1988년 영화·뉴욕 노숙인 지원 단체(midnightrun.org)·달리기 대회와 겹쳐서 Korea를 붙임. midnightrunkorea.com·midnightrunkorea.vercel.app 비어 있음(2026-11-26 확인). 'hagwon'·'blacklist'는 쓰지 않음. 소개 문구는 'Avoid the midnight run — check before you sign'처럼 **도망칠 일을 막는 곳**으로(계약 위반을 부추기는 인상 피함). 상표 등록은 확인 안 함.
- **코드명 DY-010 LOOKOUT**(사용자 2026-11-26): 망보는 사람 — 계약 전에 미리 알려 줘서 runner가 안 생기게. RUNNER도 마음에 들었지만 목적(도망을 막는 것)과 반대 뜻이라 뺌. DY-009는 언어교환 앱 몫.
- **운영 방식**(사용자 2026-11-26): 삭제·정정 요청은 사이트 안 양식 + 사이트용 새 Gmail(개인 메일 숨김) · 당분간 완전 무료(광고·학원 돈 없음) · 코드는 새 비공개 저장소 `DODO-YONG/midnight-run-korea` + Vercel 무료.
- **기획 다듬기**(사용자 2026-11-26): 영어 검색 = 자동 로마자 + 체인 영어 이름 표 + 교사가 영어 이름 추가 · 리뷰 **1건부터 공개**(3건 기준이면 처음에 텅 빔, 대신 건수 크게·퇴사 뒤 공개 권장) · 가짜 리뷰 = 구글 로그인 + 학원당 1건 + 새 계정 몰림 알림. 홍보 채널은 미정.
