# 🚀 TRACER 고도화 계획 (로그인·DB·상시 운영·관리자·문제 저장소)

상위: [[ccna-coach]]

> 2026-11-20 사용자와 정한 계획. 같은 날 코드 완료, 배포(계정 준비)는 사용자 몫 — `agents/ccna-coach/SETUP.md`. **조건: Claude 구독 외 추가 비용 0** (모든 서비스 무료 등급, 결제 수단 등록 안 함).

## 목표
- 구글 계정 로그인, 사용자별 데이터 저장(DB)
- 내 Mac 없이 **항상 동작**(터널·`start-public.sh` 은퇴)
- 관리자 페이지: 사용자 관리, 접속·활동 기록, 권한 부여·회수
- **문제 저장소**: 이전에 만든 문제를 재사용해 제미나이 호출 절약

## 구조
```
[브라우저] ─구글 로그인─▶ [Supabase Auth]
    │  (로그인 토큰)
    ▼
[Vercel: 화면 + /api 파이썬 함수] ─▶ [제미나이 무료 키]   ← 키는 Vercel 환경변수에만
    │
    ▼
[Supabase DB: 사용자·권한·활동 기록·풀이 기록·XP·문제 저장소]
```

## 서비스 선택
| 후보 | 판단 |
|---|---|
| **Vercel(Hobby) + Supabase(Free)** ✅ | 카드 불필요, 구글 로그인 내장, 파이썬 함수로 `server.py`·`gemini_client.py` 재사용 |
| Firebase | 서버 함수가 유료 요금제(Blaze) 필요 → 제외 |
| Cloudflare Pages+Workers+D1 | 무료·일시정지 없음, 대신 로그인·관리자 직접 구현(작업 2배) |
| GitHub Pages + Supabase Edge Functions | Vercel 불필요, 대신 서버를 TypeScript로 새로 작성 |

무료 운영 주의점 (착수 시 공식 요금 페이지로 재확인):
- Supabase 무료 프로젝트는 **7일 무활동 시 일시정지** → GitHub Actions(공개 저장소 무료)로 하루 1번 깨우기.
- Vercel Hobby는 **비상업용만**. 개인 공부 도구라 해당 없음.
- 두 곳 모두 **결제 수단 미등록** → 한도 초과 시 청구 없이 멈춤.
- 볼트 자동 푸시 → Vercel은 `ccna-coach` 관련 폴더가 바뀔 때만 빌드(Ignored Build Step).
- 제미나이 무료 한도가 먼저 참 → 사용자별 하루 한도 유지.

## 단계
0. **계정 준비(사용자 직접, 안내 받음)**: Vercel(GitHub 계정), Supabase 프로젝트, Google Cloud OAuth 클라이언트 → Supabase 구글 로그인 연결. 키 값은 대시보드에만, 저장소엔 `.env.example`에 변수 이름만.
1. **DB 설계**
   - `profiles`: 이메일·이름·역할(owner/admin/user)·상태(active/pending/blocked)·가입일·마지막 접속
   - `permissions`: AI 문제·내 문제 해설 사용 여부, 하루 AI 한도
   - `activity_log`: 누가·언제·무엇(로그인·문제 받기·채점·해설), 문제 내용은 요약만
   - `attempts`(풀이 기록), `progress`(XP·레벨·배지)
   - 문제 저장소: `questions`·`question_seen`·`question_reports` (아래 절)
   - RLS: 본인 데이터만, 관리자는 전체. 정답·해설 열은 서버만 읽음.
2. **서버 이전** (`server.py` → Vercel `/api`): 토큰 확인 → 권한·차단·한도 확인 → 저장소/제미나이 → 활동 기록. 정답은 서버에만, 서브넷 계산은 화면이 직접. `refuse_paid_billing` 유지.
3. **화면**: "Google로 로그인", XP·진도 계정 저장(기기 간 이어짐), 첫 로그인 때 브라우저 XP 1회 이전, 문제 신고 버튼.
4. **관리자 페이지** (`/admin`, owner·admin만)
   - 사용자: 목록·검색, 가입일, 마지막 접속, 오늘 사용량
   - 권한: 기능별 켜기/끄기, 하루 한도, 차단/해제, 관리자 지정
   - 활동 기록: 사용자별 타임라인, 기간·행동 필터
   - 대시보드: 일별 접속자, AI 사용량, 무료 한도 대비 남은 양
   - **문제은행**: 문제 보기·고치기·숨기기, 신고 검토, 정답률 이상 문제 표시
5. **배포·유지**: Vercel(`*.vercel.app`), Supabase 깨우기 Actions, 기존 github.io `/ccna/` → 새 주소로 안내
6. **정리·검증**: 실제 구글 로그인, 권한 회수 시 차단, 남의 데이터 안 보임, 저장소 출제·신고 동작 확인(시험 호출은 짧게). README·이 허브·루트 README 지도·소개 페이지 작동 방식 그림 갱신.

## 문제 저장소 (2026-11-20 추가)
현재 문제 1개당 제미나이 **2번**(문제 생성 + 채점·해설). 문제만 저장하면 1번만 줄어서 해설까지 저장한다.

- **객관식: 생성 때 해설까지 한 번에** — 정답·해설·**보기 A~D 각각 틀린 이유**를 함께 받아 저장. 채점·해설은 저장값으로 → AI 0번. 새 문제도 2번 → 1번.
- **주관식**: 문제·모범 답안·해설은 저장, 판정만 AI 1번 *(추천안 — 사용자 확인 전, 아래 미정 참고)*.
- **섞어 쓰기**: 묶음 = 범위(52) × 난이도(3) × 유형(2) = 312개.
  - 묶음에 30개 미만 → 새로 만들어 저장
  - 30개 이상 → 약 90% 저장소, 약 10% 계속 새로 생성(다양성 유지)
  - **사용자가 이미 푼 문제는 제외**, 다 풀었으면 새로 생성
- **품질 관리** (틀린 정답 키가 여러 사람에게 반복되는 위험 대비)
  - 문제 신고 버튼, 신고 N건 이상이면 자동 출제 중지
  - 문제별 정답률 기록, 비정상적으로 낮으면 정답 키 오류 의심 표시
  - 관리자 문제은행에서 검토·수정·숨김
  - 생성 시 기존 문제와 거의 같으면 저장 안 함(중복 제거)
- **제외**: "내 문제 해설"(책·기출 붙여 넣기)은 저장소에 넣지 않음 — 저작권·개인 입력. 지금처럼 매번 AI.
- **용량**: 312묶음 × 30 ≈ 9,400문제 ≈ 20MB (Supabase 무료 500MB 안).
- **선택**: GitHub Actions로 밤에 제미나이 무료 한도 안에서 조금씩 미리 채우기.
- 정상 상태 객관식은 **문제당 AI 0번**(지금 2번).
