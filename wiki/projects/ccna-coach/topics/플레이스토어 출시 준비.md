# 📱 플레이스토어 출시 준비 (traceroute)

상위: [[ccna-coach]] · 관련: [[TRACER 고도화 계획]]

> 2026-11-22 정리. 사용자 결정: **광고를 넣은 안드로이드 앱**, 문제·해설은 **앱 안에 저장**해서 꺼내 씀, 출시 이름 **traceroute**(Cisco Packet Tracer와 겹치지 않게).
> Play 정책·요금은 바뀔 수 있으니 등록할 때 Play Console 안내로 다시 확인한다.

## 0. 먼저 정할 것 (사용자)
| 항목 | 추천 | 이유 |
|---|---|---|
| 앱 만드는 방식 | **Capacitor로 감싸고 문제은행을 앱 안에 넣기** | 지금 화면(HTML·JS)을 그대로 재사용하면서 광고(AdMob)를 붙일 수 있다. TWA·PWA는 AdMob을 못 씀 |
| 서버(Vercel·Supabase·제미나이) | **앱에서는 쓰지 않음** | 광고 = 상업용 → Vercel 무료 등급(비상업 전용) 조건에 걸림. 로그인이 없으면 계정 삭제 기능·데이터 양식도 단순해짐 |
| 로그인 | 없음 | 진도·풀이 기록·틀린 문제는 기기 안에 저장 |
| 광고 위치 | 세트 결과 화면 아래 배너 | 문제 푸는 도중 전면 광고는 이탈이 큼 |
| 가격 | 무료 + 광고 | |

> ⚠️ 비용: Play 개발자 등록비 **$25(한 번)**. 이 저장소의 "추가 요금 없음" 원칙의 예외라 사용자가 직접 결정·결제한다.

## 1. 사용자가 직접 할 일 (계정·돈·신원)
- [ ] Google Play Console 개발자 계정 만들기($25), 본인 확인(신분증), 연락처 이메일·전화 인증
- [ ] **개인 계정은 정식 출시 전 비공개 테스트 필요**: 테스터 12명 이상이 14일 연속 참여(테스터 모으기 — 지인·스터디). 기준은 Console에서 재확인
- [ ] AdMob 계정 만들고 앱 등록 → 앱 ID·광고 단위 ID 받기(키·ID는 저장소 말고 `.env`나 `private/`에)
- [ ] AdMob 세금 정보·지급 계좌 입력(수익 받을 때). 광고 수익은 소득 신고 대상
- [ ] 개인정보 처리방침에 공개될 연락처 정하기(공개 저장소라 개인 이메일 노출 주의)

## 2. Claude가 할 수 있는 개발 작업
- [ ] 앱 이름 traceroute로 바꾸기(화면·소개·칭호), 칭호 `Packet Tracer`·`CCNA Ready` 다른 이름으로
- [ ] 앱용 화면 분리: 문제은행 1,808문제를 JSON으로 묶어 앱에 넣기(약 2~3MB), 서버 없이 출제·채점·해설
- [ ] 세트 풀기·마이페이지·틀린 문제 다시 풀기·XP를 **기기 저장(로컬)** 으로 옮기기, 서브넷 계산은 그대로
- [ ] 문제 신고: 서버 대신 메일/구글 폼 링크
- [ ] (선택) 문제 업데이트: 공개 사이트에 문제 파일을 두고 인터넷이 되면 새 버전 받기(비용 0)
- [ ] AdMob 배너 + **광고 동의 화면(UMP, 유럽 사용자)**, 테스트 광고 ID로 먼저 확인
- [ ] Capacitor 안드로이드 프로젝트, 앱 아이콘·스플래시, 다크 모드 기본
- [ ] 패키지 이름 정하기(예: `io.github.<아이디>.traceroute`, 한 번 정하면 못 바꿈)
- [ ] 최신 targetSdk(Play 요구 수준), 광고 ID 권한(`AD_ID`) 선언
- [ ] 서명 키(업로드 키) 만들기 → **`private/`에만 보관, 절대 커밋 금지** + Play App Signing 사용
- [ ] 릴리스용 AAB 빌드, 실제 폰·에뮬레이터 확인
- 필요 도구(무료): Android Studio, JDK, Node.js

## 3. 스토어 등록 자료
- [ ] 앱 이름(30자): `traceroute – 네트워크 자격증 문제` 같은 식. **이름에 CCNA·Cisco 넣지 않기**
- [ ] 짧은 설명(80자) / 전체 설명(4,000자): "CCNA 200-301 공부용 연습 문제"처럼 설명에서만 언급 + **비공식 고지**("Cisco·CCNA는 Cisco Systems의 상표이며 이 앱과 관계없습니다", "직접 만든 연습 문제이며 실제 시험 문제가 아닙니다")
- [ ] 아이콘 512×512, 피처 그래픽 1024×500, 휴대폰 스크린샷 2~8장(문제·해설·결과·마이페이지)
- [ ] 카테고리: 교육, 연락처 이메일, 개인정보 처리방침 URL(앱용으로 새로 — 광고 ID·AdMob·기기 저장 설명)

## 4. Play Console 정책 양식
- [ ] **데이터 보안**: 광고 ID 수집·공유(AdMob), 기기 안 저장 데이터, 서버 전송 없음
- [ ] **광고 포함** 표시
- [ ] **콘텐츠 등급** 설문(IARC)
- [ ] **타겟 연령**: 13세 이상(아동 대상 아님 → 가족 정책 제외)
- [ ] 앱 액세스: 로그인 없음(심사자 계정 불필요)
- [ ] 뉴스·건강·금융·정부 앱 아님 선언

## 5. 출시 순서
1. 내부 테스트(나만) → 2. 비공개 테스트(12명·14일) → 3. 프로덕션 출시 신청 → 4. 심사(보통 며칠) → 5. 출시
- 출시 뒤: 신고·별점 확인, 정답률 낮은 문제 점검, 문제 업데이트

## 지금 웹(TRACER)과의 관계
- 웹은 그대로 운영(로그인·DB·관리자). 앱은 같은 문제은행을 쓰는 **별도 오프라인 버전**.
- 웹에서 만든 기능(세트·마이페이지·틀린 문제 다시 풀기, 2026-11-22)을 앱에서는 기기 저장 방식으로 옮긴다.
