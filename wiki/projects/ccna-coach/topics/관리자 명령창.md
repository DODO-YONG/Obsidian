# 💬 관리자 명령창 (웹 TRACER 관리자 페이지)

상위: [[ccna-coach]] · 관련: [[TRACER 고도화 계획]]

**웹 데모의 관리자 페이지 전용**(안드로이드 앱 Tracer Route와는 무관). 관리자 페이지 맨 위 입력칸에 말로 명령하면, 그 명령을 **이미 화면에 있는 필터·버튼**으로 실행한다. AI가 DB를 직접 건드리지 않는다.

## 흐름
1. **규칙 먼저**(화면 `admin.html`의 `ruleCommand`): 기간(“1년”, “한 달”, “며칠”)·대상(신고·미접속·승인 대기…)·동사(보여줘/몇 명/지워줘)를 정해진 표현으로 알아듣는다. 제미나이를 부르지 않아 정확하고 무료 한도도 아낀다.
2. 규칙으로 안 되면 **제미나이**(`/api/admin/ask`): 정해진 명령 목록(enum)에서 하나만 고르게 하고, 예시를 주고, 온도 0.1. 서버가 값을 허용 목록 안으로 다시 맞춘다(`clean_command`). 명령 문장만 보낸다(이메일은 지워서 보냄, 사용자 데이터·DB 내용은 안 보냄). 명령 문장은 기록하지 않는다.
3. **확신 70% 미만**이면 바로 실행하지 않고 “이렇게 이해했어요: …. 맞나요?” → [맞아요, 실행]/[아니에요].
4. 실행 결과는 5종으로 구분해 최근 6개를 보여 준다.

| 표시 | 뜻 |
|---|---|
| 화면 바꿈 | 탭·필터를 바꿔 보여 줌 |
| 답변 | 숫자로만 답함, 화면은 그대로(“화면에서 보기” 버튼) |
| 실행함 | 확인창에서 ‘실행’을 눌러 데이터가 바뀜 |
| 취소 / 확인 필요 | 확인창에서 취소 / AI 확신이 낮아 대기 |
| 못 함 | 목록 밖 명령이거나 대상이 없음 |

## 할 수 있는 명령(= 화면 버튼 범위)
- 보기: 대시보드(7·14·30·90일), 사용자(상태·삭제 예정·N일 넘게 미접속), 활동 기록, 문제은행(출제 중지·정답률 낮음), 앱 신고(미처리/전체·기간).
- 숫자 답변: 전체·승인 대기·차단·삭제 예정·N일 미접속 사용자 수, 기간 접속자, 오늘 제미나이 호출, 미처리/기간 앱 신고, 출제 중지·출제 중 문제 수.
- 일괄 작업(대상 목록을 보여 주고 다시 물음): N일 넘게 미접속 사용자 **삭제 예정 표시**, 삭제 예정 모두 취소, 승인 대기 모두 승인, 미처리 앱 신고 처리 완료.
- 특정 사람 지정·문제 수정·설정 변경 등은 하지 않는다(못 함).

## 결정
- **‘지워줘’ = 삭제 예정 표시**(`profiles.delete_at`), 실제 삭제는 아직 없음. 그 사용자가 다시 접속하면 자동으로 풀린다. 실제로 지울지·유예 기간은 미정([[개발 보드]]).
- 일괄 작업은 사용자 탭·앱 신고 탭에 **버튼으로도** 있다(명령창은 그 버튼과 같은 함수를 부름). 사용자 행마다 ‘삭제 예정/예정 취소’ 버튼.
- 서버 `/api/admin/users-bulk`도 한 명씩 권한 검사(주인·자기 자신 제외, 다른 관리자는 주인만).
- 관리자(주인 외)의 명령 해석은 그 사람의 하루 AI 한도를 쓴다.

## 모의 관리자 화면 (시연용)
- 주소 `/ccna/admin.html?demo=1` — 로그인 없이 열림, 맨 위에 “모의 관리자 화면” 안내.
- 데이터는 `docs/ccna/admin-demo.js`의 **브라우저 안 가짜 DB**(지어낸 사용자 18명·신고 8건·예시 문제 7개, example.com). 실제 DB와 연결 없음, 새로고침하면 처음으로.
- 명령 해석은 같은 규칙 → 안 되면 `/api/demo/ask`(실제 제미나이, 로그인 없음, **하루 전체 30회 제한** `TRACER_DEMO_DAILY_AI`). 한도·연결 실패면 ‘못 함’으로 안내.

## 파일
- 화면: `docs/ccna/admin.html`(명령창·확인창·필터·일괄 버튼), `docs/ccna/admin-demo.js`(모의 DB)
- API: `docs/api/_core.py`(`admin_ask`·`demo_ask`·`clean_command`·`admin_users_bulk`, 대시보드·앱 신고 기간), `docs/api/index.py`
- DB: `agents/ccna-coach/supabase/admin_ai.sql`(배포 전 Supabase에서 실행)
- 시험: `agents/ccna-coach/dev/test_core.py`(서버), `agents/ccna-coach/e2e/`(화면)
