# 🧠 ccna-coach — DY-003 TRACER

> 코드명: [[에이전트 코드명|DY-003 TRACER]] · CCNA 200-301 시험 대비 코치

상위: [[00_홈]]

단원·세부 범위를 골라 문제를 받고, 답을 내면 해설을 받는 웹사이트. 화면은 공개(GitHub Pages), 답변은 내 Mac의 서버가 제미나이로.

- **화면**: https://dodo-yong.github.io/Obsidian/ccna/
- **코드**: `agents/ccna-coach/` (답변 서버), `docs/ccna/` (화면·출제 범위)
- **제미나이**: [[gemini-chat]]과 같은 무료 등급 키, 같은 모델 자동 전환 방식

## 설계 결정
- **키는 내 Mac에만**: 공개 화면에 키를 넣으면 누구나 볼 수 있다 → 화면이 `127.0.0.1:8765`의 내 서버에 묻고, 서버만 `.env`를 읽는다.
- **내 사이트 요청만 허용(CORS)**: 다른 사이트가 내 서버로 요청해 무료 한도를 쓰지 못하게 403.
- **서브넷 계산은 AI 없이**: AI가 틀리기 쉬운 계산이라 화면의 자바스크립트가 직접 만들고 채점. 서버 없이도 누구나 쓸 수 있다.
- **정답은 서버에만**: 화면에는 문제·보기만.
- **출제 범위는 한 파일**: `docs/ccna/topics.json`을 화면과 서버가 함께 읽는다(6단원 52범위, Cisco 공개 시험 주제 기준).
- 풀이 기록은 `private/`에만 → 공개 위키엔 진도·점수를 적지 않는다.

## 확인한 것 (2026-11-18)
- 서버: 내 사이트에서 온 사전 요청 204 + 허용 헤더, 다른 사이트 POST·GET 403.
- 제미나이 실제 호출 2번: OSPF DR/BDR 객관식 문제 생성(정답 노출 없음) → 오답 "A" 채점·해설(priority 0, 비선점 설명 정확).
- 화면: 서브넷 문제 생성·오답 채점·계산 해설, 연결 표시. 기록이 private에 저장되고 공개 저장소에서 제외됨.
- ❓ 아직: GitHub Pages 주소에서 실제로 내 서버에 연결되는지(브라우저의 로컬 네트워크 허용 포함).

## 누구나 쓰게 열기 (2026-11-18)
- 사용자 결정: **접속 코드 없이 누구나** 사용.
- `start-public.sh` → 서버 + Cloudflare 임시 터널 + 현재 주소를 `docs/ccna/server.json`으로 GitHub에 공개 → 화면이 자동 연결. 끄면 null로 공개.
- 무료 한도 보호: 방문자 1명당 시간당 30 · 방문자 전체 하루 300(주인 제외). 방문자에게 내 기록 비공개, 방문자 풀이 미기록, CCNA 무관 질문 거절.
- 모델: 429·503·무응답 모델은 잠시 맨 뒤로(응답 1분+ → 1~2초).
- 시험 통과: 공개 주소만 열어 자동 연결("AI 연결됨", 코드 칸 없음) → 문제 받기 → 오답 채점·해설 표시. 끌 때 "꺼짐" 자동 공개.
- ❓ 아직: 휴대폰 데이터 등 실제 다른 네트워크 기기에서 확인.

## 영어 출제 + 게임 (2026-11-18)
- 사용자 요청: CCNA는 영어 시험이라 **문제·보기·해설을 영어로**. 화면 안내(버튼 등)는 한국어 유지.
  - 서버 지시문을 영어로, 판정은 correct/partial/incorrect → 기록용 한국어로 변환. 서브넷 문제·해설도 영어.
  - 확인: native VLAN 불일치 객관식 → 영어 해설 정확.
- 🎮 게임 시스템(브라우저 저장): XP·10단계 칭호(Cable Rookie → CCNA Ready)·오늘의 퀘스트 3개·배지 14개·레벨업 화면.
  - 확인: 서브넷 6문제(5정답) → 144 XP, Lv 2, "3연속 정답" 퀘스트 완료, First Ping 배지.

## 소개 영역 + 캐시 대응 (2026-11-18)
- 사이트 맨 앞 소개(예시 카드·3단계·출제 비중·칭호 사다리). 재방문자는 자동으로 접히고 눈에 띄는 안내 카드(소개 펼치기·이어서 풀기)로.
  - 사용자가 "자동 접힘"을 "업데이트 안 됨"으로 오해 → 기능은 유지, 접힌 안내를 크게 바꿈.
- GitHub Pages는 브라우저 캐시 10분(max-age=600) → 다른 컴퓨터에서 예전 화면. `docs/version.json` + `scripts/bump-site-version.sh`로 새 버전 감지 시 한 번 자동 새로고침.
- 주소는 대소문자 구분: `/obsidian/`(소문자)는 404.

## 작동 방식 소개 (2026-11-18)
- 공개 소개 페이지에 **"TRACER 원리"** 섹션: https://dodo-yong.github.io/Obsidian/#how (코드 `docs/index.html`, 스타일 `docs/style.css`의 `.tr-*`)
  - **재생형 구성도**(SVG): 브라우저 · 임시 터널 · 내 Mac 서버 · 제미나이 · 주소 안내판(`server.json`)을 네트워크 그림처럼 그리고, 재생하면 패킷이 단계별로 이동. 탭 2개: "AI 문제"(10단계) / "서브넷 문제 · 서버 꺼져도 OK"(5단계, AI 쪽이 흐려짐). 처음 보이면 한 번 자동 재생, 단계 목록을 눌러 이동. 휴대폰에선 세로 그림.
  - **역할 트리**: TRACER → 다섯 부분 → 각자 맡은 일, 🔒 = Mac 밖으로 안 나감. 데스크톱은 조직도형, 휴대폰은 폴더 트리형.
  - 객관식 정답 판정은 AI가 아니라 서버가 함(문구에 반영).
  - (처음 버전은 카드 4개 + 스윔레인이었고, 같은 날 위 형식으로 바꿈)
  - 사용자 피드백 "다크모드에서 안 보이고 그림·글자가 허접" → 다시 디자인: 동그라미 → 큰 카드(아이콘 타일 + 18px 제목), 연결선은 꺾인 선 + 이름표(HTTPS·터널·API·주소 읽기/등록), 다크모드 전용 색(`#how`의 `--tq-*`), 단계 목록 대신 진행 막대 + 큰 설명, 트리 이모지 → 같은 선 아이콘.
  - 교훈: 다크모드는 `--rule`처럼 옅은 색을 선에 쓰면 거의 안 보임 → 도형용 색을 따로 정하고 다크 화면을 원래 크기로 확인할 것.
  - **공용 파일로 분리**: `docs/tracer-how.js`(그림·트리·문구) + `docs/tracer-how.css`(색 `--tq-*`). 소개 페이지 `#how`와 TRACER 사이트 소개 영역("HOW IT WORKS", 출제 비중·칭호 아래)이 `<div class="tq-how" data-tracer-how>`로 같이 씀 → 한 곳만 고치면 둘 다 바뀜. 캐시 대비로 `?v=` 붙이고 `bump-site-version.sh`가 함께 올림.
  - 공개 문구 원칙(사용자 요청): "제 Mac·내 Mac" 대신 **"개인 서버", "개인 컴퓨터 환경"** 같은 공식 표현.
  - 설계 이유 4개: 키는 Mac에만, 정답은 서버에만, 계산은 코드로, 추가 비용 없음.
  - 확인: 데스크톱(어둡게)·모바일(밝게) 화면, 가로 스크롤 없음.
