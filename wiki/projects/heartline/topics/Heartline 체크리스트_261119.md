## 0. 준비

- [ ] `cloudflared` 설치 확인

## 1. 답변 서버 (`server/`)
- [ ] `server.py`: 파이썬 표준 라이브러리 서버, 포트 8766
- [ ] `GET /api/health`: 켜짐 상태 응답
- [ ] `POST /api/chat`: 답장을 글자 단위로 스트리밍(SSE)
- [ ] `gemini_client.py`: 제미나이 무료 등급 호출, 한도·바쁨이면 다음 무료 모델로 자동 전환
- [ ] `prompts.py`: 시스템 지시 순서 **안전 규칙 → 페르소나 → 모드(마음/영어) → 기억 요약**
- [ ] 마음 대화 지시: 공감부터, 질문 하나씩, 진단·약 조언 금지
- [ ] 영어 모드 지시: 자연스러운 대화 + 교정은 최대 2개, 힘든 얘기면 마음 대화로
- [ ] 답장을 짧은 말풍선 1~3개로 나눠 보내도록 지시
- [ ] 교정 카드·위기 신호를 답장 본문과 분리해서 화면에 따로 전달
- [ ] 🔒 `safety.py`: 위기 표현 감지, 미성년 페르소나 거부, 전화번호·이메일 가림, 메시지 길이 제한
- [ ] 🔒 대화 본문을 파일·로그에 남기지 않기
- [ ] 배포한 화면 주소에서 온 요청만 받기(CORS), 방문자별 사용량 제한

## 2. 화면 (`docs/heartline/`)
### 입장·페르소나 (F1)
- [ ] 🔒 입장 화면: 19세 이상 확인, "AI이며 상담을 대신하지 않음", 제미나이 처리·개인정보 안내 → 동의해야 입장
- [ ] 프리셋 3종: 다정한 연상 / 장난꾸러기 동갑 / 차분한 지적인 타입 (성별 선택)
- [ ] 직접 만들기: 이름·성별·호칭·성격·말투·사귄 날
- [ ] 🔒 미성년 나이대는 선택 불가

### 대화방 (F2)
- [ ] 메신저 배치: 프로필 사진·이름·**AI 표시**·상태 메시지 / 말풍선 / 입력창
- [ ] 입력 중 "···" 표시 → 말풍선이 차례로 도착
- [ ] 보낸 시각, 날짜 구분선, 읽음 "1"
- [ ] 말풍선 두 번 탭 → 💗 반응
- [ ] 대화·페르소나를 브라우저(IndexedDB)에 저장, 새로고침해도 유지
- [ ] 일정 턴마다 기억 요약 → 다시 오면 상대가 지난 이야기를 이어 감
- [ ] 따뜻한 피치–로즈 디자인, 밤 테마, 휴대폰 화면(폭 360px)에서 깨지지 않음

### 위기 대응 (F3)
- [ ] 🔒 🆘 버튼이 대화방에 항상 보임 → 도움 받을 곳(109·1577-0199·112·119)
- [ ] 🔒 위험 표현이면 캐릭터를 멈추고 안부 확인 + 도움 카드
- [ ] 🔒 브라우저 키워드 감지 + 서버(AI) 판단 2중
- [ ] 🔒 서버가 꺼져 있어도 🆘와 키워드 감지가 동작

### 영어 모드 (F4)
- [ ] 상단 🇬🇧 토글, 켜면 같은 상대가 영어로 대화
- [ ] 틀린 문장 아래 교정 카드(고친 문장 + 짧은 이유)
- [ ] 위기 신호가 오면 영어 모드 자동으로 끄기

### 그 밖의 화면
- [ ] 설정: 페르소나 수정, 대화 전체 삭제
- [ ] `server.json`으로 서버 주소 자동 연결, 꺼져 있으면 "지금은 답하기 어려워요" 안내
- [ ] 🔒 입력창 아래 "나를 알 수 있는 정보는 빼고 말해 주세요", 전송 전 전화번호·이메일 가림
