- [x] ⭐ 페르소나 카드에 모든 설정 반영: 성격 키워드·슬라이더·말투·이모지·말버릇·호칭·관계 단계·사귄 날·직업·관심사·좋아하는 것·싫어하는 것
- [x] ⭐ "이 사람답게, 일관되게" 지시 (AI 도우미 말투 금지)

- [x] 🔒 `safety.py`: 위기 표현 감지, 미성년 페르소나·키워드 4개 이상 거부, 개인정보 가림, 길이 제한
- [x] 🔒 대화 본문을 파일·로그에 남기지 않기
- [x] 배포 화면 주소만 허용(CORS), 손님 사용량 제한
