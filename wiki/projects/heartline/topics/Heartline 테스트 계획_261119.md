# 🧪 Heartline 테스트 계획 (3단계)

상위: [[heartline]] · 기준: [[Heartline PRD_261119]] · [[Heartline 체크리스트_261119]]

> 구현 **전에** 테스트를 먼저 썼다. 테스트가 "서버가 이렇게 동작해야 한다"는 약속이 되고, 4단계 개발은 이 테스트를 통과시키는 것이 목표.
> 보기 좋은 페이지: https://dodo-yong.github.io/Obsidian/heartline/tests.html (수동 시나리오 통과/실패를 바로 기록, 브라우저 저장)
> 두 가지로 나눈다: **① 자동 테스트**(가짜 AI, 사용량 0) · **② 수동 시나리오**(실제 앱·실제 AI, 사람이 확인)

## ① 자동 테스트 — `agents/heartline/server/tests/`
설치할 것 없음(파이썬 기본 `unittest`). 실제 AI 대신 **가짜 AI** → 무료 한도를 쓰지 않는다.

```bash
cd agents/heartline/server
python3 -m unittest discover -s tests -v
```
**결과(2026-11-19, 4단계 구현 뒤): 50/50 통과.**

| 파일 | 시험하는 것 | 개수 |
|---|---|---|
| `test_prompts.py` | ⭐ **페르소나 카드에 사용자가 정한 모든 항목**(키워드·말버릇·직업·좋아하는 것·싫어하는 것·관계·말투)이 들어감 · ⭐ 관계 단계별로 카드가 달라짐 · ⭐ "일관되게" 규칙 · 지시 순서(안전 → 페르소나 → 모드 → 기억) · 모드별 규칙 · 답장을 말풍선(최대 3)·교정·위기 신호로 나누기 | 16 |
| `test_safety.py` | 성인 페르소나 통과·미성년 거부·키워드 4개 이상 거부 · 위기 문장 30개 전부 감지 · 일상 50개 오탐 3개 이하 · 개인정보 가림 · 메시지 길이 | 14 |
| `test_server.py` | 스트리밍 · 태그가 화면에 안 보임 · 영어 교정 이벤트 · 위기 문장이면 high · AI로 가기 전 개인정보 가림 · 400/403/429 · 대화 본문 무기록 · 유료 키 거부 | 16 |
| `test_gemini_client.py` | 무료 모델 자동 전환 · 전부 막히면 오류 · 지시 전달 | 4 |
