# 🧪 Heartline 테스트 계획 (3단계)

상위: [[heartline]] · 기준: [[Heartline PRD_261119]] · [[Heartline 체크리스트_261119]]

> 구현 **전에** 테스트를 먼저 썼다. 테스트가 "서버가 이렇게 동작해야 한다"는 약속이 되고, 4단계 개발은 이 테스트를 통과시키는 것이 목표.
> 보기 좋은 페이지: https://dodo-yong.github.io/Obsidian/heartline/tests.html (수동 시나리오 통과/실패를 바로 기록, 브라우저 저장)
> 두 가지로 나눈다: **① 자동 테스트**(가짜 AI, 사용량 0) · **② 수동 시나리오**(실제 앱·실제 AI, 사람이 확인)

## ① 자동 테스트 — `agents/heartline/server/tests/`
설치할 것 없음(파이썬 기본 `unittest`). 실제 AI 대신 **가짜 AI**를 써서 무료 한도를 쓰지 않는다.

```bash
cd agents/heartline/server
python3 -m unittest discover -s tests -v
```
지금은 구현 전이라 4개 묶음 모두 **건너뜀(skip)**. 모듈을 만들면 자동으로 실행된다.

**서버가 지켜야 할 약속(테스트에 적힌 모양)**
- `safety.py`: `detect_risk` · `mask_pii` · `validate_persona` · `check_message`
- `prompts.py`: `build_system_prompt` · `parse_reply`
- `server.py`: `make_server` · `refuse_paid_billing` · `/api/health` · `/api/chat`(SSE: token·correction·risk·done)
- `gemini_client.py`: `GeminiClient` · `RateLimited` · `AllModelsBusy`
- 손님 구분: Cloudflare 터널을 거친 요청(`CF-Connecting-IP` 헤더) = 손님 → 사용량 제한
