# 🚀 SHADOW 출시 계획

상위: [[shadowing-coach]]

> 2026-11-22 사용자와 아이디어 검토 결과. **개발은 아직 시작하지 않음.** 지금 쓰는 개인용 SHADOW(내 Mac, 유튜브 내려받기)는 그대로 둔다.

## 결론 (방향)
**크롬 확장 프로그램**으로 만든다. 사용자가 원래 보던 **유튜브·넷플릭스 화면 위에서** 동작하는 "섀도잉 전용 녹음기"다.
- 영상은 건드리지 않고 **내 목소리만** 다룬다 → 저작권 걱정이 거의 없고, 넷플릭스도 되고, 이어폰을 써도 된다.
- 영상 멈춤·되감기·이어 재생은 확장이 **대신 해 준다** → 손으로 조작하는 번거로움을 없앤다.
- 처리는 모두 **사용자 기기 안에서** 한다 → 서버비 0원. 사용자가 늘어도 비용이 늘지 않는다.

## 검토한 대안과 결론
| 대안 | 결론 | 이유 |
|---|---|---|
| 지금 구조 그대로(yt-dlp로 유튜브 소리 내려받기) | ❌ | 유튜브 약관 위반이고 앱스토어 심사에서 거절된다. 개인용으로만 쓴다 |
| 맥 내장 영한사전(비공개 API) | ❌ (출시판) | 비공개 API는 심사 거절 대상이다. 출시판은 공개 사전 데이터나 공식 사전 화면을 쓴다 |
| 유튜브 공식 플레이어로 재생만 + 대본은 사용자가 붙여 넣기 | 보류 | 가능하지만 원본 억양 곡선이 빠지고, 결국 웹 안에서만 된다 |
| 스피커 소리를 마이크로 같이 녹음해서 원본 분석 | ❌ (사용자 판단) | 음질을 보장할 수 없고, 이어폰을 써야 할 때가 있다 |
| 앱은 녹음만, 영상 조작은 사용자가 손으로 | 보완 | 손으로 멈추고 되감는 건 번거로워서 결국 안 쓰게 된다 → 크롬 확장으로 자동화 |
| **⭐ 크롬 확장(유튜브·넷플릭스 위에서 동작)** | **채택** | 위의 장점을 모두 가지면서 조작을 자동화할 수 있다 |
| 맥 메뉴바 앱(재생/정지 키를 대신 누름) | 후보 | 어떤 앱에서든 되지만, 남에게 배포하려면 Apple 등록 연 $99가 든다 |

## 저작권 원칙
- 영상·소리·자막을 **내려받거나 저장하지 않는다.** 확장은 플레이어 조작(멈춤·되감기·재생)과 마이크 녹음만 한다.
- 프렌즈 같은 드라마는 워너 브러더스 저작권(공개 후 95년)이다. 앱 이름이나 홍보에 작품명을 쓰지 않는다(상표 문제).
- 원본 억양 곡선이 필요한 "파일 모드"는 **사용자가 가진 파일**이나 **공공 저작물**만 쓴다.
  - 후보: VOA Learning English(https://learningenglish.voanews.com/). 미국 정부 저작물이라 대부분 공공 저작물이고, 쉬운 영어 오디오와 대본이 있다.
  - 단, 통신사 기사·일부 사진은 제외되고, 2025년 이후 새 콘텐츠가 계속 올라올지는 불확실하다.

## 기능 범위
| 동작 | 유튜브 | 넷플릭스 | 비고 |
|---|---|---|---|
| Space 누름 → 영상 자동 멈춤 + 녹음 | ⭕ | ⭕ | 사이트의 Space 단축키를 확장이 먼저 가로챈다 |
| 뗌 → 바로 내 녹음 재생 | ⭕ | ⭕ | |
| 내 녹음이 끝나면 영상 자동 이어 재생 | ⭕ | ⭕ | 켜고 끌 수 있다 |
| R → 3~5초 되감아 원본 다시 듣기 | ⭕ | ⭕ | 넷플릭스는 내부 플레이어 기능을 써야 한다(비공식이라 업데이트 때 고칠 수 있음) |
| C → 원본 구간 → 내 녹음 이어 듣기 | ⭕ | ⭕ | |
| 내 발음 받아 적기 | ⭕ | ⭕ | 기기 안 Whisper(transformers.js) |
| 문장 단위 되감기(켜진 자막 기준) | 나중 | 나중 | 화면 자막을 읽는 방식이라 선택 기능으로 조심히 |
| 원본 억양 곡선 비교 | ❌ | ❌ | 파일 모드에서만 |

- 마이크 권한은 사이트별이 아니라 **확장에서 한 번만** 허용받는다(오프스크린 문서에서 녹음).
- 녹음은 사용자 기기에만 저장한다. 목소리는 민감 정보이므로 서버로 보내거나 활용하지 않는다.

## 수익화
- 크롬 웹스토어에는 결제 기능이 없다(2020년쯤 종료) → 외부 결제 서비스를 붙인다.
- **부분 유료(무료 + 프로)**를 기본으로 한다.
  - **무료**: 자동 멈춤, 녹음, 바로 재생, 되감아 듣기, 이어 듣기. 매일 쓰게 만드는 기본기라 무료로도 충분히 좋아야 한다.
  - **프로**: 발음 받아 적기·대본 비교, 기록 무제한·성장 그래프, 파일 모드 억양 곡선, 여러 기기 동기화.
  - 가격 형태는 **한 번 결제(평생)**와 **월 구독** 중 나중에 정한다.
- 결제 후보:
  - ExtensionPay: 확장 전용이라 가장 쉽다. 뒤에서 Stripe를 쓰는데, 한국 개인 가입이 가능한지 확인이 필요하다.
  - Lemon Squeezy, Paddle: 해외 세금 처리를 대신해 주는 판매 대행이다.
  - 토스페이먼츠, 포트원: 국내 결제이고 보통 사업자등록이 필요하다.
- 수수료는 매출의 약 5~10%다. 수익이 계속 생기면 사업자등록과 세금 신고를 확인한다.
- 광고와 녹음 데이터 활용은 하지 않는다.
- 현실적인 기대: 무료 사용자 중 1~5%가 결제한다. 먼저 무료로 내서 사용자를 모으고, 많이 쓰는 기능을 확인한 뒤 프로를 붙인다.

## 비용
- 나와 지인이 쓰는 시험판: **0원**(크롬에 직접 설치).
- 크롬 웹스토어 공개 출시: 등록비 **$5(한 번)**. Claude 구독 외 비용이므로 출시 전에 사용자가 결정한다.
- 서버: 없음(기기 안에서 처리).

## 경쟁·차별점
- 비슷한 서비스: 스픽, 말해보카(회화·단어), ELSA(발음 점수), Language Reactor(유튜브·넷플릭스 자막 문장 반복, **녹음 없음**).
- 차별점: **보던 영상 위에서 누르는 순간 녹음하고 떼면 바로 재생**하는 빠른 반복이다. 나중에는 억양 곡선 시각화(파일 모드)도 내세운다.

## 단계
1. **시험판**: 유튜브에서 "Space로 멈춤 + 녹음 → 떼면 재생 → R로 되감기"만 되게 만들어 내 크롬에 설치하고 직접 써 본다.
2. **넷플릭스 지원** + 이어 재생·이어 듣기 + 날짜별 기록.
3. **발음 받아 적기**(기기 안 Whisper).
4. 지인 몇 명에게 써 보게 한다 → 계속 쓰는지, 어떤 기능을 많이 쓰는지 확인한다.
5. 크롬 웹스토어 무료 출시($5, 사용자 결정) — 개인정보 처리방침 필요(TRACER 때 경험 있음).
6. 반응이 좋으면 프로 기능과 결제를 붙인다.

## 열린 질문
- 결제 방식: 한 번 결제 vs 구독, 가격.
- 확장 이름: "SHADOW"를 그대로 쓸지(DY 코드명은 내부용).
- 파일 모드(억양 곡선)를 확장에 넣을지, 별도 웹앱으로 둘지.
