# 🕶️ shadowing-coach — DY-008 SHADOW

> 코드명: [[에이전트 코드명|DY-008 SHADOW]] · 영어 섀도잉 코치 (섀도잉 + 첩보 용어 "미행")

상위: [[00_홈]]

유튜브 영상을 문장 단위로 듣고 따라 말하며 인토네이션과 발음을 확인하는 **내 Mac 전용** 앱. 원할 때 바로 녹음되고, 떼면 바로 재생되는 것이 핵심이다.

- **코드**: `agents/shadowing-coach/` (Obsidian에선 숨김) · 사용법은 `agents/shadowing-coach/README.md`
- **실행**: GitHub 바로가기 https://dodo-yong.github.io/Obsidian/shadow/ → "SHADOW 열기"(= http://127.0.0.1:8777/). 서버는 `autostart.sh on`으로 로그인 때 자동 실행(LaunchAgent, 2026-11-20 켬) · 수동은 `SHADOW 실행.command`
- **기술**: 파이썬 기본 기능 서버 + 브라우저 화면, yt-dlp·ffmpeg·whisper.cpp(`whisper-cli`, base.en 모델)

## 설계 결정 (2026-11-20, 사용자와 아이디어 검토 후)
- **내 Mac에서 나만 쓴다**: 로컬 서버(127.0.0.1)만, 외부 접속 거부. 추가 비용 0원, 외부 AI 전송 없음.
- **자료는 유튜브 위주 → A 방식(소리·자막 내려받기)**: 화면에 넣은 유튜브는 보안 정책 때문에 소리를 분석할 수 없다. 그래서 yt-dlp로 소리를 내려받아 분석하고, 화면에는 유튜브 영상을 그대로 띄운다. 탭 소리를 캡처하는 B 방식은 매번 허락이 필요하고 구간 자르기가 번거로워 제외했다.
  - 유튜브 약관상 회색지대라 **개인 학습용으로만** 쓰고, 내려받은 파일은 `data/`(git 제외)에만 둔다.
- **스피커로 원본을 다 들은 뒤 녹음**(동시 섀도잉 아님): 원본 소리가 녹음에 섞이지 않는다. 그래서 이어폰이 필요 없다.
- **녹음은 누르고 있는 동안만**(Space 또는 버튼), 떼면 바로 재생한다. 영상을 그냥 보다가 눌러도 멈추고 그 문장으로 녹음한다.
- **속도 조절은 넣지 않음**(사용자가 필요 없다고 함).
- **Whisper를 1단계에 넣음**: 자동 자막은 마침표가 없고 조각나 있다. 그래서 자막 대신 Whisper로 받아 적어 ① 문장 나누기 ② 발음 체크를 함께 해결한다.
- **녹음은 날짜별로 쌓음**: 문장마다 `data/<영상>/rec/<문장>/<날짜_시각>.wav/.json`에 저장하고, 기록에서 예전 녹음을 다시 듣고 그래프로 볼 수 있다.
- **억양 비교는 "모양"만**: 남녀·개인마다 목소리 높이가 달라서, 각자의 중앙값을 기준으로 반음 단위로 바꾼다. 말 빠르기 차이는 DTW로 맞춘 뒤 상관계수로 점수를 낸다. 계산은 모두 브라우저 안에서 한다(`pitch.js`, YIN).
- **발음 체크의 한계를 화면에 그대로 표시**: Whisper는 문맥으로 단어를 보정하므로 "알아들음 %"로 표시한다. 음소 단위 점수는 3단계로 미뤘다(무료 모델이 무겁고 정확도가 들쭉날쭉함). 유료 발음 평가 API는 비용 원칙 때문에 제외했다.
- **무음 녹음은 버림**: Whisper가 무음에서 "You" 같은 말을 지어낸다. 그래서 가장 큰 50ms 구간이 -45dBFS 이하면 Whisper에 보내지 않고 기록에도 남기지 않는다.
- **효과음 표시 제거**: Whisper가 붙이는 `[Music]`·`[Applause]`·`(laughs)`·♪는 문장에서 뺀다.

- **단어 뜻은 맥 내장 뉴에이스 영한사전**(사용자 요청, 2026-11-20): 무료이고 로컬에서 동작하며 한국어 뜻이 나온다. 사전 검색 기능(DictionaryServices, Swift 도우미 `tools/dict.swift`)으로 같은 철자 항목을 모두 받아 온 뒤, 예문·숙어는 빼고 품사별 핵심 뜻만 보여 준다.
  - 첫 항목만 쓰면 `stories`→"층", `I`→알파벳·요오드처럼 틀려서, 동음이의어 번호순으로 정렬하고 철자가 같은 표제어만 남긴다.
  - `-ed`·`-ing`는 기본형의 동사 뜻을 먼저 보여 준다(graduated → graduate "졸업하다").
  - 외부 사전 API나 제미나이는 쓰지 않는다. 단어가 민감 정보는 아니지만, 사전만으로 충분하고 오프라인에서도 되기 때문이다.
- **GitHub 링크로 바로 열기**(사용자 요청): 소리 내려받기·Whisper·맥 사전 때문에 공개 웹만으로는 동작할 수 없다. 그래서 완전 온라인 버전 대신 GitHub Pages `docs/shadow/`에 "SHADOW 열기" 버튼(→ 127.0.0.1:8777)을 두고, 서버는 로그인 때 자동 실행하게 했다. 페이지에서 로컬 서버 상태를 미리 확인하지 않는 이유는, 크롬의 로컬 네트워크 접근 허락 창이 뜨기 때문이다. 버튼은 단순 이동만 한다.
- **단축키는 키 위치(e.code)로 판단**: 한글 입력 상태에서는 R이 `ㄱ`으로 들어와 동작하지 않던 문제(사용자 제보)를 고쳤다.
