# 🎤 interview-coach — AWS 리더십 원칙 면접 코치

상위: [[00_홈]]

AWS 인턴십 행동 면접(16 Leadership Principles)을 연습하는 대화형 에이전트.
경험 은행을 읽고 **약한 원칙부터** 질문 → **꼬리 질문 2~3개** → 5개 항목 평가 → 연습 기록 저장.

- **코드**: `agents/interview-coach/` (Obsidian에선 숨김)
- **기술**: Claude Agent SDK(Python), 커스텀 도구 7개, 기본 모델 `claude-opus-5-5`
- **실행**: `agents/interview-coach/run.sh` → 언어 모드(ko/en/mix)·원칙 선택

## 설계 결정
- **코드와 개인 데이터 분리**: 코드는 공개, 경험·연습기록은 git 제외 구역에만 읽고 씀.
  시작 시 데이터 폴더가 git 제외인지 검사하고, 아니면 저장 거부.
- **도구 제한**: 코치 전용 도구만 허용, 파일·명령 등 기본 도구는 차단.
- **사실 지어내지 않기**: 답변 뼈대는 사용자가 말한 사실로만, 빈 곳은 `[수치 필요]`.
- **AI와 본인 기여 구분 질문**: 면접관이 반드시 파고들 지점을 코치가 미리 묻도록 함.

## 평가 항목
STAR 구조 · 본인 행동(I) · 결과 구체성(수치) · 원칙 적합도 · 전달력 — 각 1~5점 + 종합.
