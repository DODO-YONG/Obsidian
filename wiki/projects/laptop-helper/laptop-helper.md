# 🧹 laptop-helper — DY-006 SWEEPER

> 코드명: [[에이전트 코드명|DY-006 SWEEPER]] · 랩탑(홈 폴더) 정리 도우미

상위: [[00_홈]]

볼트 밖, 홈 폴더 전체를 대상으로 하는 첫 에이전트. 다운로드·데스크탑 정리, 흩어진 문서를 위키 `raw/`로 모으기, 폴더를 종류별로 정리.

- **코드**: `agents/laptop-helper/` (Obsidian에선 숨김)
- **기술**: Claude Agent SDK(Python), 커스텀 도구 8개, 기본 모델 `claude-sonnet-5-5`(가벼운 일이라 사용량 절약)
- **실행**: `./run.sh`(대화) · `./run.sh scan` / `docs [키워드]` / `plan <폴더>`(AI 없음, 사용량 0)

## 설계 결정
- **범위를 줄여 시작**(사용자 요청): 디스크 용량·중복 파일·개발 폴더 정리는 다음으로. 첫 버전은 정리·문서 모으기·폴더 정리 3가지.
- **스캔은 코드, 판단·설명은 AI**: 파일 목록·크기·분류는 파이썬이 정확하고 공짜 → AI는 결과를 읽고 제안만. 보고서만 볼 땐 AI를 아예 안 씀.
- **승인은 사람이 터미널에서 직접**: 쓰기 도구가 실행 직전에 `input()`으로 y/N을 묻는다. AI의 권한 설정이 아니라 코드에서 막으므로 AI가 우회할 수 없음.
- **휴지통만**: Finder `delete`(되돌리기 가능). 영구 삭제 기능 자체가 없음.
- **보호 구역**: 키·인증서·`~/Library`·`~/.config`·볼트 `private/`·비밀 파일 이름은 목록도 안 봄(`safety.py`).
- **볼트는 건드리지 않음**: 볼트 안 파일은 옮기기·지우기 금지. 위키로는 `raw/projects/<프로젝트>/`에 복사만 → 이후 Claude Code에서 "ingest 해줘".
- **개인 정보**: 파일 이름은 개인 정보 → 작업 기록·보고서는 `private/laptop-helper/`에만. 공개 문서에 실제 파일 이름을 적지 않는다.

## 확인한 것 (2026-11-18)
- 안전 규칙: `~/.ssh`·`~/Library`·`private/`·`.env`·홈 밖은 읽기·쓰기 거부, 볼트 파일은 읽기만, 다운로드 안 파일은 쓰기 허용.
- 시험 폴더(`~/sweeper-selftest`, 끝나고 삭제): 종류별 정리, 숨김 파일·하위 폴더 그대로, 다시 돌리면 옮길 것 0개.
- 승인: 복사·정리·휴지통 모두 `n`이면 아무 변화 없음, `y`면 실행. 볼트 파일·`~/.ssh`는 휴지통 대상에서 자동 제외.
- 실제 다운로드·데스크탑 스캔(읽기만): 약 8초, 휴지통 후보 30여 개 검출(설치파일·중복 이름·압축 푼 zip). 문서 찾기 정상.
- ❓ 아직: 대화 모드 실제 실행(구독 사용량이 들어 사용자가 직접), Finder 휴지통 실제 동작(처음에 macOS 허용 필요).
