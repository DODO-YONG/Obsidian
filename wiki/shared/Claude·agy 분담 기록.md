# ⚖️ Claude·agy 분담 기록

상위: [[Claude·Gemini 협업 작업지시서]] · 관련: [[Claude·agy 코드 작업 비교 실험_261123]]

**목적**: 실제 작업에서 일을 어떻게 나눴을 때 **효율적이고 정확한지** 당분간 비교한다(사용자 요청 2026-11-23). 실험이 아니라 평소 작업을 그대로 기록한다.

## 기록하는 법
- 여러 단계 작업(코드 여러 파일, agy를 부른 작업)이 끝날 때마다 Claude가 표에 **한 줄** 추가한다.
- 칸: 작업 · 나눈 방식 · 줄 수(agy / Claude / Claude 도우미) · agy 호출 수 · 찾은 문제(누가 몇 건, 진짜였는지) · 다시 고친 것 · 메모
- Claude 사용량은 세션 사용량을 알 수 있을 때만 적는다(대략). 정확히 못 재면 `–`.
- 판단 기준: ① 같은 결과에 Claude 사용량이 적은가 ② 놓친 버그가 적은가 ③ 다시 고친 양이 적은가 ④ 전체 시간이 짧은가.
