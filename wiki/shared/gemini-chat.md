# 💬 gemini-chat — DY-004 TWIN

> 코드명: [[에이전트 코드명|DY-004 TWIN]] · 터미널에서 제미나이와 대화

상위: [[00_홈]]

터미널에서 구글 제미나이에게 질문하는 파이썬 스크립트. 사용자가 다른 터미널의 Claude Code로 만들었다(2026-11-18).

- **파일**: `scripts/gemini.py` (표준 라이브러리만 사용 — 설치할 것 없음)
- **키**: 볼트 루트 `.env`의 `GOOGLE_API_KEY` (git 제외). 코드에는 키가 없다.
- **대화 기록**: `~/.local/state/gemini-chat.json` (볼트 밖, 본인만 읽기 권한) → git·Obsidian에 안 들어감

## 쓰는 법
| 명령 | 하는 일 |
|---|---|
| `python3 scripts/gemini.py` | 대화 모드 (앞 대화 기억). `/new` 새 대화, `/exit` 끝 |
| `python3 scripts/gemini.py "질문"` | 한 번만 묻기 |
| `python3 scripts/gemini.py -c "질문"` | 지난 대화에 이어 묻기 |
| `python3 scripts/gemini.py --new` | 저장된 대화 기록 지우기 |
| `GEMINI_MODEL=모델명 python3 scripts/gemini.py ...` | 모델 지정 |

## 동작 방식
- Gemini REST API(`generateContent`)를 직접 호출. 키는 URL이 아니라 요청 헤더(`x-goog-api-key`)로 보낸다.
- **모델 자동 전환**: `gemini-3.8-flash` → `gemini-3.7-flash` → `gemini-3.1-flash-lite` 순서로 시도.
  바쁨(503)·한도 초과(429)·모델 없음(404)·시간 초과면 다음 모델로 넘어간다(앞 모델은 30초, 마지막은 120초 대기).
- 성공한 질문·답변만 기록에 추가 → 실패해도 대화가 꼬이지 않음.

## 💸 비용·개인정보
- **무료 등급** (사용자 확인, 2026-11-18) → 추가 요금 없음. 결제가 필요한 설정으로 바꾸지 않는다.
- 무료 등급에서는 보낸 내용이 구글의 서비스 개선에 쓰일 수 있다.
- **규칙(사용자 지시)**: 개인정보·비자·면접 경험·`private/` 내용·키는 제미나이에 **절대 보내지 않는다.**
  Claude도 이 스크립트로 그런 내용을 보내지 않는다.
