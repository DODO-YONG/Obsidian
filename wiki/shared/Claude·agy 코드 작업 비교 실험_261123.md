# 🧪 Claude·agy 코드 작업 비교 실험 (2026-11-23)

상위: [[Claude·Gemini 협업 작업지시서]]

**질문**: 코드를 짤 때 "Claude가 먼저 짜고 agy가 검토" vs "agy가 먼저 짜고 Claude가 검토·수정" 중 무엇이 나은가?

## 방법
- **과제**: [[소개팅 앱 기획_261123]] 1단계 — DB 9개 테이블 + 권한(RLS) + 핵심 함수 7개(`migration.sql` 한 파일). 두 쪽에 같은 명세·같은 지시문.
- **채점**: 결과를 보기 전에 만든 비공개 시험 37개(PGlite = 진짜 Postgres를 WASM으로). 참고 답안으로 시험 자체를 먼저 검증(37/37).
- **Claude**: 서브에이전트(Opus 5.5 기본). **agy**: `scripts/gemini.sh`(AI Pro 한도, Claude 사용량 0).
- Claude 사용량은 서브에이전트가 보고한 토큰 수(대략값).

- Claude → agy 코드(B): 9건(높음 0·중간 2·낮음 7). 동시성 2건을 고침. 보안 구멍은 없었음.

## 결론
1. **이 정도 난이도에선 agy도 처음부터 만점**이다. 실력 차이는 시험 점수로는 안 보였다. agy는 3배쯤 느리고 코드가 길었다.
2. **agy가 먼저 짜도 Claude 사용량은 줄지 않았다**(B 97k ≈ A 95k). 긴 코드를 Claude가 읽고 공격 시험을 짜는 데 토큰이 들었다.
3. **agy 검토가 쓸모 있었다**: Claude 사용량 0으로 진짜 문제 8건을 찾아 줬다.
4. **agy의 생각 강도를 올려도**(xhigh) 시험 점수는 같고 시간만 늘었다. 무거운 모델이 꼭 필요하지 않다.
5. → **코드는 "Claude가 짜고 agy가 검토"**를 기본으로 한다. 반복·본보기 따라 하기·문서는 agy가 먼저 해도 된다(이번엔 재지 않음).
