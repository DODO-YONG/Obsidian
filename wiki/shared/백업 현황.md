## 결정
- **맥에서도 구글 드라이브 전체 백업을 쓴다** (사용자 결정, 2026-11-25).
  - 본인 전용 공간이라 랩탑과 같은 보안 등급으로 보고 `.env`를 포함한 볼트 전체를 백업한다.
  - 스크립트: `scripts/backup-gdrive.sh` (`rclone sync`, 변경·삭제된 파일은 `_archive/날짜`에 보관, `.git/`·`node_modules/`·`.venv/` 등 재생성 가능한 부산물만 제외)
  - 자동 실행: `scripts/com.dodo-yong.obsidian-gdrive-backup.plist` (1시간마다, `launchd`)
  - 최초 1회 터미널에서 `rclone config create gdrive drive scope=drive`로 구글 로그인 필요.
- `private/`는 **비공개 GitHub 저장소**로도 백업한다 (2026-11-18 설정).
  - `private/` 폴더 자체가 별도 git 저장소 → `DODO-YONG/Obsidian-private` (PRIVATE)
  - 백업: `scripts/backup-private.sh` — 바뀐 게 있을 때만 커밋·푸시, **푸시 전 저장소가 비공개인지 확인**하고 아니면 멈춤
  - 커밋 전 키 검사(`../.githooks`)도 똑같이 적용. `.env`는 여기에도 넣지 않음
  - Obsidian Git 자동 커밋은 공개 저장소만 다룬다 → private 백업은 **자동이 아님**

## 구글 드라이브 `security-agent-backup` (Windows 시절)
- Windows PC의 Ubuntu(WSL)에서 1시간마다·매일 23:50·폴더 잠글 때 백업하던 것.
- **마지막 백업: 2026-11-18 08:32 (한국 시간)**. 그 뒤로 없음 → 맥으로 옮긴 뒤의 작업은 들어 있지 않다.
- 내용: security-agent 코드(커밋 `c7f4cd3`까지)와 점검 리포트, 새 PC 복원 키트(`env/`).
- 이 Mac에는 드라이브 백업이 설정돼 있지 않다(rclone은 설치돼 있으나 로그인·자동 실행 없음).
- Windows PC를 다시 켜고 작업 폴더를 열면 예전 사본을 다시 백업하기 시작한다(자동 푸시는 저장소가 보관 처리돼 실패).

## Windows → 맥 이전
- Windows에서 커밋해 둔 기록이 GitHub에 남아 있어서, 맥에서 `git subtree`로 **이력째** 가져와 이어서 작업했다. ([[security-agent]])
- 같은 방식으로, 이 볼트도 어느 컴퓨터에서든 `git clone` 한 번이면 복원된다. `private/`는 비공개 저장소를
  `git clone https://github.com/DODO-YONG/Obsidian-private.git ~/Obsidian/private`로 받는다. `.env`는 따로.
  (커밋 전 검사 다시 켜기: 볼트에서 `git config core.hooksPath .githooks`, private/에서 `git config core.hooksPath ../.githooks`)
