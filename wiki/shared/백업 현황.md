# 💾 백업 현황

상위: [[00_홈]]

어디에 무엇이 백업되는지. (2026-11-18 확인)

| 대상 | GitHub | 구글 드라이브 | 비고 |
|---|---|---|---|
| 위키·에이전트 코드 (`wiki/`, `agents/`, `docs/` 등) | ✅ 자동 (Obsidian Git, 편집 5분 멈추면) | ❌ | 커밋 이력 전체가 남음 |
| `private/` (면접 경험 은행 등) | ❌ 일부러 제외 | ❌ | ⚠️ **현재 이 Mac에만 있음 — 백업 없음** |
| `.env` (구글 키) | ❌ 일부러 제외 | ❌ | 키는 다시 발급 가능 |
| security-agent 점검 리포트 (`reports/`) | ❌ 일부러 제외 | (예전 것만) | |

## 결정
- **맥에서는 구글 드라이브 백업을 쓰지 않는다** (사용자 결정, 2026-11-18). 드라이브 백업을 제안·설정하지 않는다.
- 그래서 `private/`는 현재 백업이 없다. 필요해지면 무료 대안: Time Machine(외장 디스크), 또는 `private/`만 담는 **비공개** GitHub 저장소.

## 구글 드라이브 `security-agent-backup` (Windows 시절)
- Windows PC의 Ubuntu(WSL)에서 1시간마다·매일 23:50·폴더 잠글 때 백업하던 것.
- **마지막 백업: 2026-11-18 08:32 (한국 시간)**. 그 뒤로 없음 → 맥으로 옮긴 뒤의 작업은 들어 있지 않다.
- 내용: security-agent 코드(커밋 `c7f4cd3`까지)와 점검 리포트, 새 PC 복원 키트(`env/`).
- 이 Mac에는 드라이브 백업이 설정돼 있지 않다(rclone은 설치돼 있으나 로그인·자동 실행 없음).
- Windows PC를 다시 켜고 작업 폴더를 열면 예전 사본을 다시 백업하기 시작한다(자동 푸시는 저장소가 보관 처리돼 실패).

## Windows → 맥 이전
- Windows에서 커밋해 둔 기록이 GitHub에 남아 있어서, 맥에서 `git subtree`로 **이력째** 가져와 이어서 작업했다. ([[security-agent]])
- 같은 방식으로, 이 볼트도 어느 컴퓨터에서든 `git clone` 한 번이면 복원된다. 단 `private/`·`.env`는 따로 옮겨야 한다.
  (`git config core.hooksPath .githooks`로 커밋 전 검사도 다시 켤 것)
