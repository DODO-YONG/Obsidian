CCNA 200-301 시험 대비 코치. 단원과 세부 범위를 고르면 실제 시험처럼 영어로 문제를 내고, 답을 내면 고른 보기가 왜 틀렸는지까지 영어로 해설합니다. 구글 계정으로 로그인하면 진도가 계정에 남습니다.

작동 순서 · 자세히
  1. 단원·범위 선택
  2. 영어 문제
  3. 내 답
  4. 영어 해설 + XP
  • Vercel(화면·서버)과 Supabase(로그인·DB) 무료 등급으로 항상 운영. 키와 정답은 서버에만

  • 사람마다 하루 사용량 제한, 관리자 페이지에서 권한·차단·활동 기록·신고된 문제 관리
  • 서브넷 계산은 AI 없이 코드가 출제·채점 (로그인 없이도 사용)
  • XP·레벨·칭호(Cable Rookie → CCNA Ready)·오늘의 퀘스트·배지

작동 순서 · 자세히
  1. 스캔 (AI 없음)
  2. 정리 제안
  3. 직접 승인
  4. 옮기기·휴지통

  • 옮기기·복사·휴지통은 실행 직전에 터미널에서 사람이 직접 승인. 지우기는 휴지통으로만
  • 키·인증서·앱 데이터·비공개 폴더는 목록도 보지 않음, 파일 내용은 읽지 않음

CUPID

초기 버전 · 공개
Heartline 열기 → PRD 보기 → 발표 보기 → 코드 보기 →

Heartline: 내 취향대로 만드는 나만의 가상 연인 웹앱. 성격·말투·호칭·관계를 정해 연인을 만들고, 메신저처럼 대화합니다. 부가로 영어 모드가 있습니다.

작동 순서 · 자세히
  1. 페르소나 만들기
  2. 메신저 대화
  3. 영어 모드 교정
  4. 내 브라우저에 저장
  • 프리셋 6종 + 직접 만들기, 실시간 미리보기. 최대 5명을 바꿔 가며 대화
  • 입력 중 표시·여러 말풍선·읽음·하트 반응으로 실제 메신저 느낌
  • 대화·페르소나는 방문자 브라우저에만, 서버는 저장하지 않음. AI 고지·성인 캐릭터만·위기 시 도움 안내
  • PRD → 체크리스트 → 테스트 먼저 → 구현 → 발표, 하루에 다섯 단계 (자동 테스트 55개 통과)
DY-008 · agents/shadowing-coach

SHADOW

초기 버전 · 개인용 · 비용 0원
SHADOW 열기 → 코드 보기 →

영어 말하기를 위한 섀도잉 코치. 유튜브 주소를 넣으면 문장 단위로 나눠 주고, 한 문장을 들은 뒤 Space를 누르고 있는 동안 따라 말하면 떼는 순간 바로 내 목소리를 들려줍니다. 원본과 내 억양 곡선, 음성 인식이 알아들은 단어를 바로 비교하고, 모르는 단어는 눌러서 뜻을 봅니다.

작동 순서 · 자세히
  1. 유튜브 주소
  2. 문장 나누기
  3. 듣고 따라 말하기
  4. 억양·발음 비교
  5. 날짜별 기록
  • 누르는 동안만 녹음하고 떼면 바로 재생. 영상을 그냥 보다가 눌러도 멈추고 그 문장으로 녹음
  • 억양 곡선: 각자 평균 목소리를 기준으로 반음 단위로 바꾸고 말 빠르기 차이를 맞춰, 오르내림 모양만 비교 (YIN·DTW, 브라우저 안에서 계산)
  • 발음 체크: 음성 인식(Whisper)이 알아들은 단어를 원문과 비교해 다르게 들린 단어를 표시. 무음에서 말을 지어내는 문제는 소리 크기로 먼저 거름
  • 단어 뜻: 단어를 누르면 컴퓨터에 내장된 영한사전으로 품사별 짧은 뜻. graduated처럼 바뀐 형태는 기본형 동사 뜻까지
  • 소리 내려받기·음성 인식·사전 모두 개인 컴퓨터 안에서 처리해 외부 AI 호출·추가 비용 없음. 내려받은 소리와 녹음은 공개 저장소에 올리지 않음
  • 녹음은 문장마다 날짜별로 쌓여 첫 녹음과 오늘 녹음을 비교. 로그인하면 자동으로 켜지고 이 페이지에서 바로 열림
