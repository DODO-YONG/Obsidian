SENTINEL

초기 버전
코드 보기 → 1일차 작업 기록 →

URL을 주면 공격 없이 응답만 읽어 웹사이트의 보안 약점을 찾고, 위험도와 고치는 법을 리포트로 써 줍니다.

작동 순서 · 자세히
  1. 권한 확인
  2. 헤더·쿠키·TLS·본문 점검
  3. 리포트 저장
  • 점검 전에 그 사이트를 점검해도 되는지 먼저 묻기
  • 공격 요청은 보내지 않고 응답만 읽기
  • 연습용 취약 사이트로 시험해 봄
DY-002 · agents/interview-coach

MIRROR

초기 버전
코드 보기 →

AWS 16가지 리더십 원칙 행동 면접을 연습합니다. 약한 원칙부터 묻고, 꼬리 질문으로 파고든 뒤 평가합니다.

작동 순서 · 자세히
  1. 내 경험 읽기
  2. 질문 + 꼬리 질문
  3. 5개 항목 평가
  4. 연습 기록
  • STAR 구조, 수치, 원칙과 맞는지 등을 보고 피드백
  • 연습 기록이 쌓이면 약한 원칙부터 다시 질문
  • 개인 경험 기록은 공개 저장소에 올리지 않음
DY-003 · agents/ccna-coach

TRACER

초기 버전 · 공개
사이트 열기 → 작동 방식 보기 → 코드 보기 →

CCNA 200-301 시험 대비 코치. 단원과 세부 범위를 고르면 실제 시험처럼 영어로 문제를 내고, 답을 내면 영어로 해설합니다.

작동 순서 · 자세히
  1. 단원·범위 선택
  2. 영어 문제
  3. 내 답
  4. 영어 해설 + XP
  • 화면은 이 사이트에 공개하고, 답변은 키를 보관한 개인 서버가 제미나이로 생성. 키는 개인 서버 밖으로 나가지 않음
  • 누구나 접속하면 바로 사용. 서버를 켜면 현재 주소를 알아서 찾아 연결
  • 방문자 사용량 제한으로 무료 한도 보호, 방문자 기록은 남기지 않음
  • 서브넷 계산은 AI 없이 코드가 출제·채점 (서버가 꺼져 있어도 사용)
  • XP·레벨·칭호(Cable Rookie → CCNA Ready)·오늘의 퀘스트·배지
DY-006 · agents/laptop-helper

SWEEPER

초기 버전
코드 보기 →

개인 컴퓨터의 홈 폴더를 정리해 주는 도우미. 다운로드·데스크탑 현황을 보고하고, 흩어진 문서를 위키로 모으고, 폴더를 종류별로 나눕니다.

작동 순서 · 자세히
  1. 스캔 (AI 없음)
  2. 정리 제안
  3. 직접 승인
  4. 옮기기·휴지통
  • 파일 목록·분류는 코드가 계산하고, AI는 결과를 설명하고 제안만 함 (보고서만 볼 땐 AI 사용 0)
  • 옮기기·복사·휴지통은 실행 직전에 터미널에서 사람이 직접 승인. 지우기는 휴지통으로만
  • 키·인증서·앱 데이터·비공개 폴더는 목록도 보지 않음, 파일 내용은 읽지 않음
DY-007 · agents/heartline

CUPID

초기 버전 · 공개
Heartline 열기 → PRD 보기 → 발표 보기 → 코드 보기 →

Heartline: 내 취향대로 만드는 나만의 가상 연인 웹앱. 성격·말투·호칭·관계를 정해 연인을 만들고, 메신저처럼 대화합니다. 부가로 영어 모드가 있습니다.

작동 순서 · 자세히
  1. 페르소나 만들기
  2. 메신저 대화
  3. 영어 모드 교정
  4. 내 브라우저에 저장
  • 프리셋 6종 + 직접 만들기, 실시간 미리보기. 최대 5명을 바꿔 가며 대화
  • 입력 중 표시·여러 말풍선·읽음·하트 반응으로 실제 메신저 느낌
  • 대화·페르소나는 방문자 브라우저에만, 서버는 저장하지 않음. AI 고지·성인 캐릭터만·위기 시 도움 안내
  • PRD → 체크리스트 → 테스트 먼저 → 구현 → 발표, 하루에 다섯 단계 (자동 테스트 55개 통과)
DY-004 · DY-005

그 밖에 DY-004 TWIN(scripts/gemini.py, 터미널 제미나이 대화)과 DY-005 PRIMER(agents/beginner-faq, 초보자 FAQ 받기)가 있습니다.
