02에이전트

에이전트

코드명(DY-00x)으로 관리합니다. SENTINEL·MIRROR·SWEEPER는 Python 에이전트, TRACER·CUPID는 웹 서비스, SHADOW는 외부 API 없이 로컬에서 동작합니다. 개발 도구와 자동화 구성은 개발 환경에 있습니다.

DY-001 · agents/security-agent

SENTINEL

프로토타입
코드 → 개발 기록 →

비침습 웹 보안 점검. 공격 요청 없이 응답(헤더·쿠키·TLS·본문)만 분석해 위험도와 조치 방법을 리포트로 작성합니다.

구성
  1. 권한 확인
  2. 헤더·쿠키·TLS·본문 점검
  3. 리포트 저장
  • 점검 전 대상 권한 확인 필수
  • 읽기 전용 요청만 사용
  • 의도적 취약 사이트로 검증
DY-002 · agents/interview-coach

MIRROR

프로토타입
코드 →

AWS 리더십 원칙(16개) 행동 면접 코치. 취약한 원칙을 우선 질문하고, 꼬리 질문 후 5개 항목으로 평가합니다.

구성
  1. 내 경험 읽기
  2. 질문 + 꼬리 질문
  3. 5개 항목 평가
  4. 연습 기록
  • STAR 구조·수치·원칙 적합도 평가
  • 연습 기록 기반 출제 우선순위 조정
  • 개인 경험 데이터는 비공개 보관
DY-003 · agents/ccna-coach

TRACER

운영 중 · 공개
데모 → 아키텍처 → 코드 →

CCNA 200-301 학습 서비스. 범위별 영어 문제와 오답 보기별 해설을 제공하고, 구글 로그인으로 진도를 계정에 저장합니다.

구성
  1. 단원·범위 선택
  2. 영어 문제
  3. 내 답
  4. 영어 해설 + XP
  • Vercel 서버리스 + Supabase(Auth·Postgres), 무료 등급 상시 운영. 키·정답은 서버 보관
  • 객관식은 문제은행(1,808문항)에서 출제해 AI 호출 0회, AI는 주관식만
  • 사용자별 일일 한도, 관리자 콘솔(권한·차단·활동 로그·신고 문항)
  • 서브넷 문제는 코드로 출제·채점(로그인 불필요)
  • XP·레벨·칭호·퀘스트·배지
DY-006 · agents/laptop-helper

SWEEPER

프로토타입
코드 →

홈 폴더 정리 에이전트. 다운로드·데스크탑 현황 보고, 문서 수집, 종류별 폴더 정리를 제안합니다.

구성
  1. 스캔 (AI 없음)
  2. 정리 제안
  3. 직접 승인
  4. 옮기기·휴지통
  • 스캔·분류는 코드가 처리, AI는 제안만 담당
  • 모든 쓰기 작업은 실행 직전 사용자 승인, 삭제는 휴지통으로만
  • 키·인증서·앱 데이터 경로 접근 차단, 파일 내용 미열람
DY-007 · agents/heartline

CUPID

프로토타입 · 공개
데모 → PRD → 발표 자료 → 코드 →

Heartline: 페르소나 기반 대화형 웹앱. 성격·말투·관계를 설정한 캐릭터와 메신저 UI로 대화하며, 영어 교정 모드를 지원합니다.

구성
  1. 페르소나 만들기
  2. 메신저 대화
  3. 영어 모드 교정
  4. 내 브라우저에 저장
  • 프리셋 6종·직접 생성, 최대 5개 페르소나
  • 대화 데이터는 브라우저에만 저장(서버 미저장), AI 고지·위기 안내 등 안전 장치
  • PRD → 테스트 선작성 → 구현 → 발표를 하루에 완료(자동 테스트 55개 통과)
DY-008 · agents/shadowing-coach

SHADOW

프로토타입 · 로컬
열기 → 코드 →

영어 섀도잉 코치. 영상 음성을 문장 단위로 분할하고, Space를 누르는 동안 녹음해 원본과 억양 곡선·인식 단어를 즉시 비교합니다.

구성
  1. 유튜브 주소
  2. 문장 나누기
  3. 듣고 따라 말하기
  4. 억양·발음 비교
  5. 날짜별 기록
  • 억양: 반음 정규화 + DTW로 속도 차이를 맞춰 곡선 모양 비교(YIN, 브라우저 계산)
  • 발음: 로컬 Whisper 인식 결과를 원문과 대조, 무음 구간 환각 필터링
  • 사전: 시스템 내장 영한사전으로 품사별 뜻·기본형 조회
  • 모든 처리 로컬 실행, 외부 API·비용 없음. 녹음은 문장별 날짜 기록
