개인정보 처리방침

시행일: 2026년 11월 20일 · 서비스: TRACER (https://tracer-eosin.vercel.app/ccna/)

한눈에 보기
  • 구글 로그인으로 받은 이메일과 이름, 그리고 풀이·이용 기록만 저장해요.
  • 비밀번호와 IP 주소는 저장하지 않아요. 로그인은 구글이 처리해요.
  • 정보를 팔거나 광고에 쓰지 않아요.
  • 원하면 언제든 계정과 기록 삭제를 요청할 수 있어요.

1. 누가 운영하나요

TRACER는 개인 개발자(GitHub DODO-YONG)가 CCNA 공부를 돕기 위해 만든 무료·비공식 학습 도구입니다. Cisco와 관계없습니다.

2. 저장하는 정보

항목내용언제
계정 정보구글 계정의 이메일 주소, 이름(프로필 이름)처음 로그인할 때
풀이 기록받은 문제, 내 답, 정답 여부, 레벨·XP·배지문제를 풀 때

신고 내용"신고하기"에 적은 내용신고할 때

3. 저장하지 않는 정보

  • 비밀번호 — 로그인은 구글이 처리하며 TRACER는 비밀번호를 받지 않습니다.
  • IP 주소 — 서비스 기록에 저장하지 않습니다. (호스팅 업체가 보안을 위해 자체적으로 남기는 기본 접속 기록은 있을 수 있습니다.)
  • 결제 정보 — 서비스가 무료라 받지 않습니다.

4. 어디에 쓰나요

  • 로그인과 본인 확인
  • 진도·레벨을 계정에 저장해 다른 기기에서도 이어 쓰게 하기
  • 무료 AI 사용량을 사람마다 공평하게 나누기(하루 사용 한도)와 부정 이용 막기
  • 틀린 문제를 찾아 고치는 등 서비스 품질 관리

구글 계정에서 받는 정보는 이메일·이름(기본 프로필)뿐이며, 위 목적 외에는 쓰지 않습니다. 구글 사용자 데이터는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 판매하거나 광고에 쓰지 않습니다.

5. 함께 쓰는 서비스

TRACER는 아래 서비스를 이용해 동작합니다. 이 서비스들은 TRACER를 위해 정보를 처리할 뿐, 다른 목적으로 받지 않습니다.

서비스하는 일전달되는 정보
Google 로그인로그인구글 계정 확인

"내 문제 해설"에 붙여 넣은 내용은 해설을 위해 Gemini로 전송되므로 개인정보를 넣지 마세요. 붙여 넣은 문제는 다른 사용자에게 공유되지 않습니다.

6. 얼마나 보관하나요

계정을 쓰는 동안 보관하고, 삭제를 요청하면 계정 정보와 풀이·이용 기록을 지체 없이 삭제합니다. 서비스를 종료하면 모든 정보를 삭제합니다.

7. 내 권리와 삭제 요청

내 정보의 확인·수정·삭제를 요청할 수 있습니다. 서비스에서 언제든 로그아웃할 수 있고, 구글 계정 설정의 타사 연결에서 TRACER 접근을 해제할 수도 있습니다.

문의·삭제 요청: GitHub 저장소 Issues에 "TRACER 계정 삭제 요청"이라고 남겨 주세요. 이메일 주소는 공개 글에 적지 마세요. 본인 확인 방법을 안내해 드립니다.
