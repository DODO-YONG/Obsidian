확인 중…

모의 관리자 화면 — 지어낸 사용자·신고·활동으로 동작하고 실제 데이터는 바뀌지 않아요. 새로고침하면 처음 상태로 돌아가요.
    이 화면의 버튼으로 할 수 있는 일만 해요. 결과마다 화면 바꿈 · 답변 · 실행함 · 취소 · 못 함으로 표시해요. 지우기·승인 같은 작업은 대상을 보여 드리고 한 번 더 물어봐요. 해석 방식은 오른쪽에서 고를 수 있어요(모의 화면 기본: 제미나이 우선, 사이트 전체 하루 100회까지·넘으면 규칙으로). 이름·이메일은 적지 마세요(명령 문장은 제미나이로 전송돼요).

    지금 확인하거나 처리할 것들이에요. 카드를 누르면 해당 목록이 필터가 걸린 채로 열려요.

    조회 결과

    명령창에 "최로 시작하는 사용자", "지난달 가입했는데 문제 안 푼 사람"처럼 물어보면 제미나이가 읽기 전용 SQL을 만들고, 이 브라우저 안의 모의 데이터에서 실행해요(실제 데이터베이스와 무관). SELECT로 시작하는 SQL을 직접 입력해도 돼요.

    아직 조회한 결과가 없어요.

    명령창 명령과 화면에서 직접 한 일괄 작업이 어떤 단계를 거쳤는지 보여요. 데이터를 바꾼 작업은 오른쪽 되돌리기 버튼이나 명령("3번 되돌려줘", "승인한 거 되돌려줘")으로 되돌릴 수 있어요(새로고침 전 작업만). 다시 실행("3번 다시 실행해줘")은 같은 문장을 한 번 더 실행해요: 입력 → 해석(규칙 / AI·확신) → 해석된 명령 → 확인창 → 결과. 이 기록은 이 브라우저에만 저장되고 어디로도 보내지 않아요(최근 300건).
