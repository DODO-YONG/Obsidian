만든 과정

한 번에 다 만든 게 아니라, 필요할 때마다 한 칸씩 쌓아 올렸습니다.

  1. 1

    첫 웹페이지: 에이전트 소개 페이지

    "영어 공부 콘텐츠 제공 에이전트"를 소개하는 페이지를 만들고, 예시 요청을 한 번에 복사하는 버튼을 미니 기능으로 넣었습니다.

    HTML · CSS복사 버튼
  2. 2

    보안 점검 에이전트 만들기

    URL을 주면 응답 헤더·쿠키·인증서·페이지 본문을 살펴 취약점을 찾고, "왜 위험한지 · 어떻게 뚫릴 수 있는지 · 어떻게 고치는지"를 리포트로 써 주는 대화형 에이전트입니다.

    Claude Agent SDKPython공격 없는 비침습 점검
  3. 3

    허가된 데모 사이트로 예시 점검

    테스트용으로 공개된 취약 데모 사이트를 점검해, 실제로 문제를 찾아내는지 확인하고 첫 리포트를 저장했습니다.

    데모 사이트권한 없는 사이트 차단 확인
  4. 4

    Windows 안에 Ubuntu 들이기

    WSL2로 Ubuntu를 설치하고 사용자 mj를 만들었습니다. Python, Claude Code를 Ubuntu 안에도 설치했습니다.

    WSL2Ubuntu 26.04Claude Code
  5. 5

    GitHub와 연결하고 자동 저장

    GitHub에 로그인하고 저장소를 만든 뒤, 10분마다 바뀐 내용을 자동으로 올리는 타이머를 켰습니다. 커밋 작성자는 실제 이메일 대신 GitHub의 비공개 주소를 씁니다.

    gh CLIsystemd 타이머비밀값 감지 시 푸시 중단
  6. 6

    항상 켜져 있는 환경

    WSL은 원래 아무것도 안 하면 스스로 꺼집니다. 꺼지지 않게 설정하고, Windows에 로그인하면 Ubuntu가 화면 없이 자동으로 켜지게 했습니다.

    .wslconfig시작 프로그램
  7. 7

    비밀번호로 잠기는 "클라우드" 폴더

    ~/cloud를 암호화 폴더로 만들고 프로젝트를 그 안으로 옮겼습니다. 잠겨 있으면 디스크에는 알아볼 수 없는 암호문만 남습니다.

    gocryptfscloud-open / cloud-close
  8. 8

    구글 드라이브 백업

    1시간마다(지난 백업 이후 바뀐 게 있을 때만), 그리고 매일 밤 23:50에 구글 드라이브로 백업합니다. 최신본과 함께 날짜별 마지막 상태를 따로 남깁니다.

공격을 흉내 내지 않고, 웹사이트가 평소에 돌려주는 응답만 읽어서 약점을 찾습니다.

🧾

응답 헤더·쿠키

서버 버전 노출, 빠진 보안 헤더, 쿠키의 Secure·HttpOnly·SameSite 설정을 확인합니다.

🔐

HTTPS·인증서

암호화 연결이 되는지, 인증서가 만료되지 않았는지, 발급자는 누구인지 봅니다.

📄

페이지 본문

에러 메시지, 주석 속 정보, 디렉터리 목록처럼 밖으로 새어 나오면 안 되는 것을 찾습니다.

⚠️
허락받은 사이트에만 씁니다. 점검하기 전에 사이트마다 "이 사이트를 점검할 권한이 있나요?"라고 묻고, 확인된 곳만 점검합니다. 허락 없이 남의 사이트를 점검하는 것은 법에 어긋날 수 있습니다.

구글 드라이브 폴더 구성

security-agent-backup/
├─ snapshots/   시각별 사진 (덮어쓰지 않음)
├─ current/     최신 상태 (열람용)
├─ daily/       날짜별 마지막 상태 (열람용)
└─ env/         새 PC 복원 키트

새 PC로 옮길 때

드라이브의 env 폴더를 내려받아 안내서 7단계를 따르면 됩니다. Windows 설정 → Ubuntu 설치 → 로그인 → 암호화 폴더 → 복원 순서이고, git 기록과 리포트까지 그대로 돌아옵니다.

안전장치

공개 저장소와 자동 업로드를 쓰는 만큼, 실수로 새어 나가지 않게 여러 겹으로 막았습니다.

  • 점검 리포트, .env, 키 파일은 GitHub에 올라가지 않음
  • API 키·토큰·개인키처럼 보이는 내용이 있으면 자동 푸시를 멈춤 (가짜 키로 시험 완료)
  • GitHub와 겹치면 강제로 덮어쓰지 않고, 이 PC 작업을 별도 브랜치에 안전하게 보관
  • 푸시나 백업이 실패하면 Windows 알림
  • 작업 폴더는 비밀번호로 잠기는 암호화 폴더
  • 구글 드라이브 권한은 "백업 도구가 만든 파일만" 접근
  • 드라이브 백업은 덮어쓰지 않고 쌓기만 함. 최근 7일은 전부, 90일까지 하루 1개 보관
  • 복원 키트에는 로그인 정보를 넣지 않음. 새 PC에서 다시 로그인

매일 쓰는 명령

Ubuntu 창에서 입력합니다. 오른쪽 버튼으로 바로 복사할 수 있습니다.

① 작업 폴더 열기 (비밀번호 입력)
cloud-open
② 프로젝트에서 Claude Code 시작
cd ~/cloud/security-agent && claude
보안 점검 에이전트 실행
~/run-security-agent.sh
지금 바로 드라이브 백업
~/bin/gdrive-backup.sh
자동 푸시 기록 보기
journalctl --user -u autopush.service -n 20
③ 끝나면 잠그기 — 푸시·백업 후 잠금 (claude 먼저 종료)
cloud-close
