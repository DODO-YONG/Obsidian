💗 Heartline 시작하기 — 내 취향대로 만든, 나만의 가상 연인
(그림이 있는 안내서: 같은 폴더의 "시작하기.html"을 브라우저로 여세요)

필요한 것: 파이썬 3.9 이상 (https://www.python.org/downloads/)
AI 키가 없어도 "맛보기 모드"(미리 써 둔 답장)로 바로 체험할 수 있어요. 비용 없음.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🚀 3단계로 실행하기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1) 압축 풀기
   - heartline.zip 을 원하는 곳에 풀면 Heartline 폴더가 생겨요.
   - 윈도우: 오른쪽 클릭 → "모두 압축 풀기" (압축 파일 안에서 바로 실행하지 마세요)

2) 실행 파일 더블클릭
   - 맥: "Heartline 실행.command"
     처음엔 "확인되지 않은 개발자" 경고 → 파일 오른쪽 클릭 → 열기 → 열기
   - 윈도우: "Heartline 실행.bat"
     "Windows의 PC 보호" 창 → 추가 정보 → 실행

3) 키 질문에 답하기 → 브라우저가 자동으로 열려요
   - 키가 없으면 그냥 엔터 → 맛보기 모드
   - 키가 있으면 붙여 넣고 엔터 → 진짜 AI (다음부터는 안 물어요)
   - 브라우저가 안 열리면 창에 나온 주소(보통 http://127.0.0.1:8766)를 직접 여세요

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💗 앱에서 해 볼 것
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 입장 화면 두 칸 체크 → 시작하기
2. + 새 연인 만들기 → 프리셋 6종 중 하나 (츤데레·존댓말 타입 추천)
   성격·말투·말버릇을 바꾸면 미리보기 인사가 바로 바뀌어요
3. 이 사람과 대화하기 → "오늘 하루 너무 길었어" 보내 보기
4. 위쪽 🇬🇧 → 영어 대화 + 교정 카드
5. ‹ 로 목록에 가서 다른 연인도 만들어 비교 (최대 5명)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔑 진짜 AI로 바꾸기 (무료 키)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. https://aistudio.google.com/apikey → 구글 로그인
2. Create API key → AIza… 로 시작하는 키 복사
3. Heartline 을 다시 실행해서 붙여 넣기
   (또는 Heartline/server/.env 파일에 GOOGLE_API_KEY=복사한키 한 줄)
⚠️ 결제(카드)는 연결하지 마세요. 키는 다른 사람에게 보내지 마세요.

🔒 알아 두면 좋은 것
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 상대는 AI 캐릭터예요. 상담·치료를 대신하지 않아요. 만 19세 이상.
- 진짜 AI 모드의 메시지는 구글 제미나이(무료 등급)로 처리되며 서비스 개선에 쓰일 수 있어요.
  실명·연락처·주소는 넣지 마세요. (맛보기 모드는 아무것도 보내지 않아요)
- 대화는 이 브라우저에만 저장돼요. 지우기: 앱의 ⋯ → 연인·대화 전체 삭제

🛠️ 안 될 때
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- "파이썬이 필요해요": python.org 에서 설치. 윈도우는 "Add python.exe to PATH" 꼭 체크
- 윈도우에서 Microsoft Store가 열림: 파이썬 미설치 → 위 링크에서 설치
- 창이 바로 닫힘: 터미널에서 Heartline 폴더로 가서
     맥:     python3 start.py
     윈도우: py -3 start.py
- "지금은 답하기 어려워요": 무료 한도·인터넷 문제. 잠시 뒤 다시, 또는 server/.env 를 지우면 맛보기 모드
- 키를 잘못 넣음: server/.env 지우고 다시 실행

⏹ 끄기: 검은 창을 닫거나 Ctrl+C. 다시 실행하면 대화가 그대로 있어요(같은 브라우저).
