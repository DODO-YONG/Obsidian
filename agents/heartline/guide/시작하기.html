Heartline 시작하기

내 취향대로 만든, 나만의 가상 연인 — 압축을 풀고 3분이면 대화를 시작할 수 있어요.

✨ 설치할 프로그램은 파이썬 하나뿐이에요. AI 키가 없어도 맛보기 모드(미리 써 둔 답장)로 바로 체험할 수 있고, 무료 키를 넣으면 진짜 AI가 답해요. 비용은 들지 않아요.

🚀 3단계로 실행하기

  1. 압축 풀기
    받은 heartline.zip을 원하는 곳(바탕화면 등)에 풀어요. Heartline 폴더가 생겨요.
    윈도우: 압축 파일을 오른쪽 클릭 → 모두 압축 풀기. 압축 파일 안에서 바로 실행하면 안 돼요.
  2. 실행 파일 더블클릭

    🍎 맥

    Heartline 실행.command 더블클릭
    처음엔 "확인되지 않은 개발자" 경고가 떠요 → 파일을 오른쪽 클릭 → 열기 → 열기. (또는 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기")

    🪟 윈도우

    Heartline 실행.bat 더블클릭
    "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.
  3. 키 묻는 질문에 답하기 → 브라우저가 자동으로 열려요
    검은 창(터미널)에 "키를 붙여 넣고 엔터"가 나와요.
    • 키가 없으면 그냥 엔터 → 맛보기 모드로 바로 시작
    • 키가 있으면 붙여 넣고 엔터 → 진짜 AI (한 번 넣으면 다음부터 안 물어요)
    브라우저가 안 열리면 창에 나온 주소(보통 http://127.0.0.1:8766)를 직접 열어요.

💗 앱에서 해 볼 것

  1. 입장 화면에서 두 칸 체크 → 시작하기
  2. + 새 연인 만들기 → 프리셋 6종 중 하나 고르기 (츤데레·존댓말 타입을 추천해요). 성격·말투·말버릇을 바꾸면 위 미리보기 인사가 바로 바뀌어요
  3. 이 사람과 대화하기 → "오늘 하루 너무 길었어" 같은 말을 보내 보세요
  4. 위쪽 🇬🇧 버튼 → 영어로 대화, 틀린 문장엔 교정 카드
  5. ‹ 눌러 목록으로 → 다른 연인을 만들어 같은 말을 보내 비교해 보세요 (최대 5명)

🔑 진짜 AI로 바꾸기 (무료 키 받기)

  1. aistudio.google.com/apikey 접속 → 구글 계정으로 로그인
  2. Create API key → 만들어진 키(AIza…로 시작)를 복사
  3. Heartline 창을 닫고 다시 실행 → 키를 묻을 때 붙여 넣기
    이미 맛보기로 실행했다면: Heartline/server/.env 파일을 열어 GOOGLE_API_KEY=복사한키 한 줄을 넣고 다시 실행해도 돼요.

⚠️ 결제(카드)는 연결하지 마세요. 무료 등급으로 충분해요. 키는 내 컴퓨터의 server/.env에만 저장되고, 다른 사람에게 보내지 마세요.

🔒 알아 두면 좋은 것

  • 상대는 AI 캐릭터예요. 상담이나 치료를 대신하지 않아요. 만 19세 이상만 사용해 주세요.
  • 진짜 AI 모드에서는 메시지가 구글 제미나이(무료 등급)로 처리되며 서비스 개선에 쓰일 수 있어요. 실명·연락처·주소처럼 나를 알 수 있는 정보는 넣지 마세요. (맛보기 모드는 인터넷으로 아무것도 보내지 않아요)
  • 연인과 대화는 이 브라우저에만 저장돼요. 서버는 대화를 저장하지 않아요. 지우려면 앱의 ⋯ → 연인·대화 전체 삭제.

🛠️ 안 될 때

"파이썬이 필요해요"가 나와요python.org/downloads에서 설치. 윈도우는 설치 첫 화면에서 "Add python.exe to PATH"를 꼭 체크. 맥은 "개발자 도구 설치" 창이 뜨면 설치를 눌러도 돼요.
윈도우에서 Microsoft Store가 열려요파이썬이 아직 없다는 뜻이에요. 위 링크에서 설치한 뒤 다시 실행하세요.
창이 바로 닫혀요 / 더블클릭이 안 돼요터미널(명령 프롬프트)을 열고 Heartline 폴더로 이동해서 직접 실행:
python3 start.py      (맥)
py -3 start.py        (윈도우)
브라우저가 안 열려요창에 나온 주소를 복사해 직접 열어요 (보통 http://127.0.0.1:8766).
"지금은 답하기 어려워요"진짜 AI 모드에서 무료 한도가 잠시 찼거나 인터넷이 끊긴 거예요. 잠시 뒤 다시 보내거나, server/.env를 지우고 다시 실행하면 맛보기 모드로 돌아가요.
키가 틀렸어요server/.env 파일을 지우고 다시 실행하면 키를 다시 물어봐요.

⏹ 끄기

검은 창(터미널)을 닫거나 Ctrl+C. 다음에 다시 더블클릭하면 연인과 대화가 그대로 있어요(같은 브라우저일 때).
