# 🕶️ DY-008 SHADOW · 영어 섀도잉 코치

> 유튜브 영상을 문장 단위로 듣고 따라 말하면, **누르는 순간 녹음 → 떼면 바로 재생**하고, 원본과 내 **억양 곡선**과 **발음(알아들은 단어)**을 비교해 주는 내 Mac 전용 앱

- **상태**: 초기 버전 (개인용, 내 Mac에서만)
- **위키 메모**: [wiki/projects/shadowing-coach/shadowing-coach.md](../../wiki/projects/shadowing-coach/shadowing-coach.md)
- **비용**: 0원. AI 서비스 호출 없음(Whisper는 이 Mac에서 실행). 유료 키가 있으면 실행을 거부해요(`refuse_paid_billing`).

## 실행 방법
**바로가기: https://dodo-yong.github.io/Obsidian/shadow/** → "SHADOW 열기" (= http://127.0.0.1:8777/)

0. **추천 · 한 번만**: `./autostart.sh on` → 지금 켜지고, 이후 Mac에 로그인할 때마다 자동으로 켜져요(관리자 권한 필요 없음). 그러면 위 링크만 누르면 돼요. 끄려면 `./autostart.sh off`, 상태는 `./autostart.sh status`. 기록은 `data/shadow.log`.
1. **`SHADOW 실행.command`를 더블클릭**하면 서버가 켜지고 브라우저가 열려요. 끄려면 창을 닫거나 Ctrl+C를 누르세요.
   - 터미널에서는 `python3 start.py`로 실행해요.
2. 처음 한 번은 필요한 도구가 있어야 해요. 없으면 실행할 때 설치 명령을 알려 줘요.
   ```bash
   brew install yt-dlp ffmpeg whisper-cpp
   ```
   Whisper 모델(`models/ggml-base.en.bin`, 약 140MB)은 없으면 자동으로 한 번 내려받아요.
3. 브라우저가 처음 마이크 권한을 물으면 **허용**하세요.

## 쓰는 법
1. 유튜브 주소를 붙여 넣고 **가져오기**를 누르세요. 소리를 내려받아 Whisper가 받아 적고 문장 단위로 나눠요. 15분짜리 영상이 약 25초 걸려요.
2. 오른쪽 목록에서 문장을 누르면 영상에서 **그 문장만 재생**하고 멈춰요.
3. **Space를 누르고 있는 동안 녹음**하고, 떼면 **바로 내 녹음이 재생**돼요.
4. 그 사이에 분석이 끝나요.
   - **억양 곡선**: 원본(파랑)과 나(주황)의 음높이 오르내림을 비교해요. 각자 평균 목소리를 기준으로 맞추고, 말 빠르기 차이도 맞춰서 비교해요.
   - **발음 체크**: Whisper가 알아들은 단어를 원문과 비교해요. 초록은 알아들은 단어, 빨강은 다르게 들렸거나 빠진 단어, 회색은 원문에 없는 말이에요.
5. 모르는 단어는 **클릭하면 짧은 뜻**이 나와요. 맥에 들어 있는 **뉴에이스 영한사전**을 쓰니까 인터넷이나 AI가 필요 없고 비용도 0원이에요. 품사별 핵심 뜻 2개씩 보여 주고, "뜻 더 보기"로 더 볼 수 있어요. `graduated`처럼 변형된 단어는 기본형(graduate)의 동사 뜻도 함께 보여 줘요.
6. 녹음은 문장마다 **날짜별로 쌓여서**, 오른쪽 아래 기록에서 예전 녹음을 다시 듣고 비교할 수 있어요.

| 키 | 동작 |
|---|---|
| `Space` (누르고 있기) | 녹음. 떼면 바로 재생. 영상을 그냥 보다가 눌러도 멈추고 그 문장으로 녹음해요 |
| `R` / `Enter` | 원본 다시 듣기 |
| `P` | 내 녹음 다시 듣기 |
| `C` | 원본 → 내 녹음 이어서 듣기 |
| `←` `→` | 이전/다음 문장 |

단축키는 한글 입력 상태에서도 동작해요(글자가 아니라 키 위치로 판단).

- 영상이 다른 사이트에서 재생이 막혀 있으면 자동으로 **소리만 재생** 모드로 바뀌어요.
- 말소리가 거의 없는 녹음은 기록에 남기지 않아요. 무음에서 Whisper가 말을 지어내는 문제를 막으려는 거예요.

## 알아 둘 한계
- **발음 체크는 "원어민이 알아듣는가" 정도**예요. Whisper는 문맥으로 단어를 보정하기 때문에, 발음이 조금 어색해도 맞다고 나올 수 있어요. 음소 단위 점수(th/r/l 등)는 3단계 과제로 남겨 뒀어요.
- 문장 경계는 Whisper가 나눈 구간을 따라서 약간 넉넉하게 잡혀요.

## 구조
```
autostart.sh             로그인 때 자동 실행 켜기/끄기 (macOS LaunchAgent)
start.py                 도구 확인 → 서버 켜기 → 브라우저 열기
server/server.py         가져오기(yt-dlp·ffmpeg·whisper-cli)·문장 나누기·단어 비교·녹음 저장 (파이썬 기본 기능만)
server/tests/            로직 시험: python3 -m unittest discover server/tests
web/index.html·app.js    화면·녹음(MediaRecorder)·유튜브 구간 재생(IFrame API)
tools/dict.swift         맥 내장 영한사전 읽기 도우미 (start.py가 처음 한 번 빌드 → tools/dict-lookup, git 제외)
web/pitch.js             억양 분석(YIN 음높이 · 반음 정규화 · DTW 모양 비교 · 그리기), 브라우저 안에서 계산
data/  (git 제외)        영상별 소리·문장·내 녹음 (개인 학습용, 공개 저장소에 올리지 않음)
models/ (git 제외)       Whisper 모델
```
